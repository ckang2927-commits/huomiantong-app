## 1. 麦克风转写

### 启动与权限
- [ ] 点击"麦克风转写"按钮后请求麦克风权限
- [ ] 权限请求弹窗显示合理
- [ ] 授权成功后按钮状态变为"监听中"
- [ ] 拒绝权限后显示明确错误提示

### 实时转写
- [ ] 对着麦克风说话，实时转写文本出现在转录面板
- [ ] 转写文本延迟在可接受范围内（< 3 秒）
- [ ] 最终转写文本准确度合理
- [ ] 无效片段（嗯、啊、太慢了）被过滤

### 停止
- [ ] 点击"停止转写"后恢复可操作状态
- [ ] 停止后不再有转写文本
- [ ] 再次点击可重新开始

### 设备选择
- [ ] 语音设置面板显示麦克风设备下拉列表
- [ ] 可选择特定麦克风设备
- [ ] 设备名称展示成人能理解的名称
- [ ] 选择设备后转写使用该设备
- [ ] 重启应用后设备选择保持

## 2. 电脑音频转写

### 启动
- [ ] 点击"电脑音频转写"后弹出来源选择
- [ ] 可选择整个屏幕或特定窗口
- [ ] 来源名称成人可理解（如"窗口：获面通"）
- [ ] 选择来源后开始转写

### 转写效果
- [ ] 播放面试相关音频，文本能正确转写
- [ ] 系统音频（非面试内容）不过度转写

### 停止
- [ ] 停止转写后恢复可操作状态
- [ ] 可重新选择来源再次开始

### 兼容性
- [ ] Windows 10 1903+ 支持电脑音频
- [ ] 不支持时显示明确提醒

## 3. 语音设置面板

- [ ] 麦克风设备下拉可刷新
- [ ] 刷新按钮不无限转圈
- [ ] 设备枚举有超时提示
- [ ] Deepgram 配置状态显示（已配置/未配置）
- [ ] 连接状态显示（连接中/已连接/已断开）
- [ ] 输入音量条随说话跳动
- [ ] 权限状态显示

## 4. 本地麦克风诊断

- [ ] 点击"本地麦克风诊断"检查麦克风硬件
- [ ] 能检测到麦克风是否能打开
- [ ] 能检测到是否有输入音量
- [ ] 诊断结果清晰可读
- [ ] 诊断不调用 Deepgram

## 5. Deepgram 连接异常

- [ ] Deepgram 连接超时后恢复可操作状态
- [ ] 余额不足（402）时显示明确提示
- [ ] 异常时提示去 API 设置测试连接
- [ ] 重新配置 Key 后可重新连接

## 6. 混合场景

- [ ] 先开麦克风，再关掉，再开电脑音频，切换正常
- [ ] 同时只允许一个转写来源
- [ ] 转写中生成回答正常
- [ ] 转写中保存会话正常
- [ ] 转写中切换页面正常

## 7. 自动回答

- [ ] 开启自动回答后，转写完成的问题自动生成回答
- [ ] 关闭后只转写不自动生成
- [ ] 自动回答队列正常
