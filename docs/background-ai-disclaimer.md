# AI 模拟内容免责声明

> 适用于背景资料补全中心中所有由 AI 生成的内容。

---

## 通用免责声明

```
以下内容由 AI 根据已有信息模拟生成，仅供参考。
它不一定是准确的，不构成事实陈述。
正式面试前请自行核实，不要直接背诵或当作确定信息使用。
```

## 短版本

```
AI 模拟参考 · 低可信度 · 仅供准备思路 · 需用户确认
```

## 场景化免责

### 公司内部细节
```
"公司内部的组织结构、团队规模、工作流程等细节基于公开信息和行业经验模拟，
不一定与实际情况一致，面试时建议用"据我了解"的口径。"
```

### 薪资相关
```
"薪资模拟基于行业平均水平估算，不代表目标公司的实际薪资结构。
不要将此作为谈判的唯一依据。"
```

### 竞品和行业位置
```
"竞品信息和行业排名来自公开报道和行业报告摘要，
信息可能滞后或带有媒体立场，建议多方核实。"
```

## UI 展示说明

- 所有 AI 模拟内容旁边显示"AI 模拟参考"标签
- 鼠标悬停或点击标签显示完整免责说明
- 保存到"其他简历"前需要用户逐条确认
- 保存后内容保留"AI 模拟参考"来源标签
