# DeepSeek 任务书：背景资料补全中心基础建设

> 用途：这份任务书交给 DeepSeek 执行。目标是先完成“背景资料补全中心”的低风险 UI、模板、文案、示例和验收脚本。真实联网搜索、AI 深度生成、保存到“其他简历”等能力是最终产品目标，但本轮由 Codex 后续接入，DeepSeek 不要先动核心链路。

## 二、绝对禁止修改

- 不修改 `src/main/**`
- 不修改 `src/preload/**`
- 不修改 Deepgram、麦克风、电脑音频、TTS
- 不修改 AI 回答生成、RAG、训练服务、流式输出
- 不修改 API Key 加密、备份恢复、删除逻辑
- 不修改真实简历保存/导入逻辑；可以做“保存到其他简历”的占位 UI 和说明
- 不新增 npm 依赖
- 不批量移动/删除文件

## 三、产品边界

这个模块叫“背景资料补全中心”，用于面试前准备：

- HR 基础信息包
- 薪资谈判包
- 公司背景包
- 工作细节包
- 进公司后勤包
- 风险回答包
- 一致性检查包

重要原则：

- 不把 AI 模拟内容写成事实。
- 每条内容必须有来源和可信度标签。
- 老板名字、内部小组、同事是谁、真实运作方式等可以做“AI模拟参考”，但必须标注“低可信，仅供准备思路，需用户确认”。
- 第一阶段 DeepSeek 只做静态 UI 和文案，不接真实网络搜索、不接真实 AI 生成、不保存到真实简历。
- 最终产品会支持联网搜索公开公司资料、调用 AI 深度总结、用户确认后保存到“其他简历”；这些核心逻辑由 Codex 后续实现。

## 五、建议 UI 草图内容

### 1. 顶部说明

文案示例：

> 背景资料补全中心用于准备简历外的 HR、薪资、公司、工作细节和入职后勤资料。生成内容会标注来源和可信度，AI 模拟内容仅供参考，正式面试前建议自行确认。

### 2. 资料包入口

- HR 基础信息包
- 薪资谈判包
- 公司背景包
- 工作细节包
- 进公司后勤包
- 风险回答包
- 一致性检查包

### 3. 来源标签

- 正式简历
- 万字简历
- 其他简历
- 用户填写
- 公开资料
- AI模拟参考
- 待确认

### 4. 可信度

- 高：可直接使用
- 中：建议复核后使用
- 低：仅供准备思路
- 待确认：不要在正式面试中说死

## 六、DeepSeek 本轮不做但要预留的最终能力

这些不是“不做”，只是本轮不让 DeepSeek 接：

| 最终能力 | 本轮 DeepSeek 做什么 | 后续 Codex 做什么 |
|----------|----------------------|-------------------|
| 联网搜索公司公开资料 | 做来源记录模板、流程图、UI 占位 | 接入真实搜索/抓取/来源去重 |
| AI 深度总结和模拟 | 做提示文案、示例输出、可信度标签 | 接入模型调用、提示词、用量统计 |
| 保存到其他简历 | 做占位按钮、命名规范、用户确认流程 | 接入真实保存、版本、撤销、RAG 读取 |
| 一致性检查 | 做报告模板、冲突字段样例 | 接入本地规则/AI 审查 |
| 公司内部细节模拟 | 做“AI模拟参考/低可信/待确认”说明 | 接入可控生成，不写成事实 |
