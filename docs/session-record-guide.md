# 获面通：会话记录整理指南

> 管理和回顾你的面试数据。

## 查看会话

- 进入"会话记录"页面
- 按候选人筛选会话
- 刷新按钮重新加载本地数据
- 打开会话查看详细问答

## 管理操作

- **重命名**：点击"更多"→"重命名"
- **删除**：点击"更多"→"删除"，或选中后批量删除
- **批量操作**：勾选多个会话后可批量导出或删除

## 导出

- **MD 导出**：纯文本 Markdown 格式
- **Word 导出**：带格式的 .docx 文件
- **批量导出**：同时导出多个会话

## 复盘看板

顶部看板自动统计：
- 高频题型及出现次数
- 平均回答质量评分
- 风险点数量
- 按候选人/时间段趋势
