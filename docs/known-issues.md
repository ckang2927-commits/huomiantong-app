# 获面通：已知问题清单

> 当前版本的已知限制和临时绕过方式。持续更新。

## 功能限制

| 问题 | 影响 | 临时绕过 | 计划修复 |
|------|------|---------|---------|
| 快捷键不支持自定义 | 无法修改快捷键绑定 | 关闭冲突软件 | 后续版本 |
| 电脑音频部分系统不支持 | 某些 Win10 版本无法使用 | 改用麦克风转写 | 依赖 Electron 升级 |
| 简历仅支持 PDF/DOCX/MD | 其他格式不支持 | 先转换为支持格式 | 暂无计划 |
| 会话不能跨设备同步 | 换电脑看不到旧会话 | 手动导出备份再导入 | 本地优先设计 |
| 未签名 exe 触发 SmartScreen | 安装时需额外点击 | 点"更多信息"→"仍要运行" | 后续可能签名 |

## 已知界面问题

| 问题 | 条件 | 说明 |
|------|------|------|
| 设置页右侧提供商卡片可能显示不全 | 屏幕宽度 < 1200px | 缩小窗口时滚动查看 |
| 模拟训练草稿恢复后无参考答案 | 旧版本保存的草稿 | 重新开始或进入下一题会自动生成 |

## 使用建议

- 定期导出备份
- 面试前开启作战室做一键检查
- 训练草稿会在进入页面时自动恢复

## 已知性能问题

| 问题 | 条件 | 说明 |
|------|------|------|
| 首次加载简历解析较慢 | PDF 简历首次导入 | 需要调用系统 PDF 解析服务，首次解析 3-10 秒，后续从缓存读取 |
| 长时间面试后内存增长 | 连续使用超过 1 小时 | 流式输出和转写数据积累，建议定期重启应用 |
| 切换候选人时轻微卡顿 | 简历较大（>10MB） | 需要重新解析和索引简历，后续会优化为异步加载 |

## 已知兼容性问题

| 问题 | 条件 | 说明 |
|------|------|------|
| Windows 10 LTSC 版本不支持电脑音频 | 特定 Win10 企业版 | 改用麦克风转写，或升级到 Win10 20H2+ |
| 某些 VPN 导致 API 连接超时 | 开启全局 VPN | 在 VPN 中配置 API 服务商直连，或使用 PAC 模式 |
| 高 DPI 缩放异常 | 缩放比例 > 150% | 部分图标和按钮可能显示偏小，建议使用 100%-150% 缩放 |
| 杀毒软件误报 exe | 部分国产杀毒 | 添加 exe 到白名单，或使用 Windows Defender |

## 已知功能缺失

| 缺失功能 | 影响 | 计划 |
|---------|------|------|
| 快捷键不支持自定义 | 无法修改或新增快捷键 | 后续版本 |
| 不支持多用户 | 不能在同一台电脑上隔离用户数据 | 本地优先设计，暂无计划 |
| 不支持跨设备同步 | 换电脑看不到旧会话 | 手动导出备份和导入 |
| 不支持 AI 服务商测速 | 无法对比各服务商延迟 | 后续通过延迟诊断功能实现 |
| 不支持自定义提示词 | 无法修改 AI 回答的生成指令 | 后续版本 |
| 不支持导出 PDF | 只能导出 MD 和 Word | 暂无计划 |

## 常见绕过方式

### SmartScreen 阻止安装
```
右键安装包 → 属性 → 常规 → 安全：勾选"解除锁定" → 应用 → 确定
重新双击安装包 → 点击"更多信息" → "仍要运行"
```

### 数据目录损坏恢复
```
1. 先尝试导出备份（设置 → 备份 → 导出）
2. 如果能导出：重命名 %APPDATA%/huomiantong/ → 重启应用 → 导入备份
3. 如果不能导出：直接重命名目录 → 重启应用 → 重新配置
```

### 无法连接 API 服务商
```
1. 确认网络能访问服务商官网
2. 检查 Base URL 是否包含 /v1 路径
3. 切换其他模型测试是否是模型本身问题
4. 联系服务商确认 Key 状态和账户余额
```
