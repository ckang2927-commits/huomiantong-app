# 背景资料保存命名规范

> 用于将背景资料包保存到"其他简历"时的文件命名规则。
> 最终产品接入后，代码会按此规则自动生成文件名。

---

## 命名格式

```
{资料包缩写}-{候选人}-{日期}.md
```

### 资料包缩写

| 资料包 | 缩写 |
|--------|:----:|
| HR 基础信息包 | hr |
| 薪资谈判包 | salary |
| 公司背景包 | company |
| 工作细节包 | work |
| 进公司后勤包 | onboard |
| 风险回答包 | risk |
| 一致性检查包 | check |

### 示例

```
hr-康超帅-2026-07-22.md
salary-康超帅-2026-07-22.md
company-林小雅-2026-07-22.md
```

## 多版本管理

如果需要保存多个版本：

```
hr-康超帅-2026-07-22-v1.md
hr-康超帅-2026-07-22-v2.md
```

## 文件内容结构

每个保存的文件头部包含元信息：

```markdown
---
title: HR 基础信息包
candidate: 康超帅
role: 数据分析师
created: 2026-07-22
updated: 2026-07-22
source: user_input, ai_simulated, public
status: user_confirmed / needs_review / draft
---

## 字段记录
...
```

## 不建议的命名

| 不建议 | 原因 |
|--------|------|
| 背景资料.md | 不够具体，无法区分候选人 |
| 康超帅资料最终版.md | "最终版"没有版本管理意义 |
| test123.md | 无意义命名 |
