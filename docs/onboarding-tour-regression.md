- 使用全屏透明点击拦截层，防止误点页面内容。
- 使用目标区域镂空高亮和边框强调当前模块。
- 每一步显示“快速了解”和“详细说明”。
- 只允许点击“下一步”推进，或点击“跳过引导”结束。
- 支持右上角跳过按钮和 `Esc` 跳过。
- 设置中心仍可主动重新打开教程。
- 面试台目标岗位可点击跳转简历库“目标岗位”字段，当前候选人可跳转“姓名”字段。
