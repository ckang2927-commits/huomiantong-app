## 1. 简历导入

### PDF 导入
- [ ] 点击"导入正式简历"可选择文件
- [ ] 选中 .pdf 文件后导入成功
- [ ] 显示文件名、大小（KB/MB）、格式（PDF）、添加时间
- [ ] 面试台回答能引用 PDF 中的内容

### DOCX 导入
- [ ] 导入 .docx 文件成功
- [ ] 显示正确的文件信息
- [ ] 回答能引用 DOCX 中的内容

### 文本/MD 导入
- [ ] 导入 .txt 或 .md 文件成功
- [ ] 显示正确的文件信息

### 其他简历 / 补充材料
- [ ] 可导入额外补充材料
- [ ] 补充材料在回答依据中出现

### 边界情况
- [ ] 导入不支持格式时提示错误
- [ ] 导入超大文件（>10MB）有提示或正常处理
- [ ] 删除简历后回答不再引用该文件内容
- [ ] 切换候选人后简历文件正确切换

## 2. 会话导出

### Markdown 导出
- [ ] 在会话记录中选择一个会话
- [ ] 点击"导出 MD"能正常生成文件
- [ ] 导出的 .md 文件内容完整：包含问题和答案
- [ ] 如果存在依据、评分、风险检测，也包含在内

### Word 导出
- [ ] 点击"导出 Word"能正常生成 .docx 文件
- [ ] 文件内容完整，格式可读
- [ ] 表格和列表在 Word 中显示正常

### 训练复盘导出
- [ ] 完成一轮模拟训练后
- [ ] 导出 MD 和 Word 包含所有轮次问题和答案
- [ ] 包含最终复盘报告内容
- [ ] 包含口语评分（如果有语音作答）

### 隐私模式影响
- [ ] 开启隐私模式后导出内容脱敏
- [ ] 脱敏不破坏文件结构和可读性
- [ ] 关闭隐私模式后导出内容正常

### 边界情况
- [ ] 空会话导出提示"没有内容"而不是生成空文件
- [ ] 导出过程中不卡死界面

## 3. 备份导入导出

### 导出备份
- [ ] 在设置 → 备份区域点击"导出备份"
- [ ] 生成 .json 文件
- [ ] 文件包含设置、会话、用量数据
- [ ] 可选择是否包含 API Key

### 导入备份
- [ ] 点击"导入备份"弹出文件选择器
- [ ] 选择备份文件后有覆盖确认提示
- [ ] 确认后数据刷新
- [ ] 导入后设置、会话、用量都正确恢复

### 边界情况
- [ ] 导入格式错误的文件提示失败
- [ ] 导入旧版本备份数据不崩溃
- [ ] 导入时应用不卡死
- [ ] 导入后切换页面验证数据完整性
