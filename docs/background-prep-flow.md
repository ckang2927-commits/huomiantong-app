# 背景资料补全流程

> 展示"输入公司/岗位 → 搜索/AI → 来源标注 → 用户确认 → 保存到其他简历"的未来完整流程。
> 当前为设计阶段，真正联网搜索和 AI 生成由 Codex 后续接入。

---

```
用户输入公司名 + 岗位名
        │
```

## 用户操作流程

### 第一次使用
```
1. 打开设置页 → 诊断日志 → 背景资料补全中心
2. 看到 7 个资料包介绍
3. 阅读来源标签和可信度说明
4. 阅读免责声明
5. 等待 Codex 接入真实功能后使用
```

### 功能完整后（后续版本）
```
1. 在面试台左侧或设置页进入补全中心
2. 选择一个资料包（如"公司背景包"）
3. 输入目标公司名称
4. 系统自动提取已有信息（来自简历）
5. 点击"联网搜索"获取公开资料（Codex 接入）
6. 点击"AI 深度总结"生成模拟参考（Codex 接入）
7. 逐条确认内容，修改或标记待确认
8. 点击"保存到其他简历"（Codex 接入）
9. 面试时 RAG 可引用这些资料
```

## 每个步骤的 DeepSeek / Codex 分工

| 步骤 | DeepSeek 已做 | Codex 后续做 |
|------|---------------|-------------|
| 1. 提取已有信息 | 字段设计、来源标签、可信度定义 | 接入真实数据读取 |
| 2. 联网搜索 | 来源记录模板、URL 格式定义 | 接入真实搜索 API |
| 3. AI 深度总结 | 示例输出、风险文案、免责声明 | 接入模型调用、提示词 |
| 4. 来源标注 | CSS 标签样式、UI 展示 | 接入动态标签渲染 |
| 5. 用户确认 | 确认清单、策略说明 | 接入交互逻辑 |
| 6. 保存 | 命名规范、占位按钮 | 接入真实文件保存 |
