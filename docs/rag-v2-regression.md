# RAG v2 本地回归说明

本回归用于验证简历证据检索是否能在不调用真实 API、不读取用户私人简历的情况下，稳定命中关键依据。

## 运行命令

```bash
npm run validate:rag
```

## 当前覆盖场景

- 第一家公司地点：首条依据应命中最早工作经历和城市。
- 最近公司地点：首条依据应命中最近工作经历和城市。
- RFM 项目：应命中“其他简历”中的 RFM 用户分层补充资料。
- 转化漏斗：首条依据应命中正式简历里的 SQL、看板和漏斗分析经历。
- 多候选人隔离：当前候选人检索不应串到 `resumeProfiles` 里的其他候选人资料。

## 当前结论

2026-08-03 本地回归通过 5/5。P3-9 可视为“本地回归通过”，但正式发布前仍需要用真实多候选人、多份简历样本复测。
