# 获面通：模型与提供商选择指南

> 帮你快速决定该用哪个 AI 模型提供商，以及什么时候用。

---

## 一句话总结

| 场景 | 推荐 |
|------|------|
| 日常面试、实时回答、性价比优先 | **DeepSeek** |
| 国内网络、需要低延迟 | **阿里百炼 DashScope** |
| 复杂推理、高质量回答 | **OpenAI** |
| 长对话、稳健表达 | **Anthropic Claude** |
| 语音转文字 | **Deepgram** |

---

## 各提供商详解

### 1. DeepSeek ⭐ 首选推荐

| 项目 | 内容 |
|------|------|
| 推荐模型 | `deepseek-v4-flash`（日常）/ `deepseek-v4-pro`（复杂问题） |
| 适合 | 日常面试实时回答、模拟训练出题和点评 |
| 为什么推荐 | 速度快、性价比高、中文理解好 |
| 注意事项 | 模型名区分大小写；部分网络可能需要代理 |

### 2. 阿里百炼 DashScope

| 项目 | 内容 |
|------|------|
| 推荐模型 | `qwen3.7-plus` / `qwen3.7-max` |
| 适合 | 国内直连场景、中文内容 |
| 为什么选 | 国内服务器延迟低，不需要代理 |
| 注意事项 | 首次使用需开通对应模型服务；Base URL 用兼容模式 |

### 3. OpenAI

| 项目 | 内容 |
|------|------|
| 推荐模型 | `gpt-4.1-mini`（日常）/ `gpt-4.1`（深度推理） |
| 适合 | 高质量回答、复杂推理、英文面试 |
| 为什么选 | 推理能力强、回答质量稳定 |
| 注意事项 | 需要网络代理；按量计费比 DeepSeek 贵；响应速度稍慢 |

### 4. Anthropic Claude

| 项目 | 内容 |
|------|------|
| 推荐模型 | `claude-3-5-haiku-latest`（快）/ `claude-3-5-sonnet-latest`（深度） |
| 适合 | 超长对话、需要稳健安全表达的场合 |
| 为什么选 | 上下文窗口大、拒绝回答少、表达自然 |
| 注意事项 | 部分模型需申请白名单；国内访问需要代理 |

### 5. Deepgram（语音转写）

| 项目 | 内容 |
|------|------|
| 推荐模型 | 无需选择模型 |
| 适合 | 所有语音转写场景（麦克风 + 电脑音频） |
| 为什么选 | 实时转写延迟低、中文识别准确 |
| 注意事项 | 免费额度 $200，用完后需绑定信用卡；按音频时长计费 |

## 多模型策略建议

### 方案一：入门（免费/低成本）

```
回答模型: DeepSeek（deepseek-v4-flash）
语音转写: Deepgram（用免费额度）
```

### 方案二：国内加速

```
回答模型: 阿里百炼（qwen3.7-plus）
语音转写: Deepgram（用免费额度）
```

### 方案三：完整体验

```
日常回答: DeepSeek（deepseek-v4-flash）
深度回答: OpenAI（gpt-4.1-mini）或 Anthropic
语音转写: Deepgram
```

## 常见误区

- ❌ **把 Deepgram Key 填到了 DeepSeek 的字段**：每个提供商只能用自己的 Key
- ❌ **选了 OpenAI 但没开代理**：国内直连不了 OpenAI
- ❌ **一个 Key 多个模型共用**：每个模型需要对应的 API Key
- ✅ **配置多个提供商，测试都通过后切换使用**：推荐的做法
