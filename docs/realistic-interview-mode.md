# 拟真面试模式

> 本文档介绍获面通的"拟真面试模式"功能——它是什么、适合谁、怎么用、以及当前设计状态。

---

## 什么是拟真面试模式？

拟真面试模式是获面通内置的一种**高强度面试模拟工具**。它不同于普通的逐题练习模式，而是模拟一场完整的线上面试流程：

- AI 扮演面试官，按设定风格和节奏提问
- 你通过麦克风实时回答，系统记录你的回答
- 每题结束后展示参考答案和即时反馈
- 整场面试结束后生成详细报告（评分、薄弱点、风险点、推荐训练）

> ⚠️ **当前状态**：配置面板和流程预览 UI 已完成，AI 面试官提问、语音作答、自动评分等核心逻辑正在接入中。

---

## 适用场景

| 场景 | 说明 |
|------|------|
| **面试前模拟** | 准备真实面试前，先用拟真模式走一遍，熟悉节奏和常见问题 |
| **薄弱点突破** | 针对某个方向（如技术选型、项目深度）做专项强化训练 |
| **压力训练** | 选择"压力面"风格，训练临场发挥和抗压能力 |
| **表达打磨** | 通过回放和评分，优化回答结构和语言表达 |

## 配置说明

在训练页面中，你可以通过"拟真面试配置"面板调整以下参数：

### 面试时长
- 可选 10 / 20 / 30 / 45 / 60 分钟，也可自定义（5-180 分钟）
- 时长控制整场节奏，时间到后自动进入复盘

### 题目数量
- 可选 5 / 10 / 15 / 20 题，也可自定义（3-40 题）
- 后续会和主动提问、追问调度器联动

### 面试难度
| 难度 | 说明 |
|------|------|
| 简单 | 以基础问题为主，适合热身 |
| 中等 | 接近普通线上面试 |
| 偏难 | 增加项目和技术追问 |
| 压力面 | 更强调查疑和临场稳定 |

### 面试侧重点
可以多选，系统后续会按这些方向组织题目：

- 项目挖掘
- 简历真实性
- 技术深度
- 业务理解
- 表达沟通
- 压力追问

### 面试官风格
| 风格 | 说明 |
|------|------|
| 温和型 | 比较温和地推进面试 |
| 追问型 | 围绕你的回答持续追问 |
| 压力型 | 偏压力面，强调查疑 |
| 技术主管型 | 更关注技术判断和取舍 |
| HR 型 | 更关注稳定性和匹配度 |
| 随机混合 | 随机切换提问风格 |

### 追问策略
| 策略 | 说明 |
|------|------|
| 固定走题 | 按题纲顺序完成 |
| 根据回答追问 | 围绕你的回答继续深挖 |
| 随机混合 | 固定题与追问随机切换 |

## 面试流程

拟真面试的完整流程如下：

```
开场 → 面试官语音提问（同步显示文字）→ 你通过麦克风回答 
→ 系统判断回答结束 → 显示参考答案和点评 
→ 追问或下一题 → ... → 整场结束 → 生成详细报告
```

### 各阶段说明

1. **开场**：AI 面试官先说明规则和节奏，让你进入状态
2. **提问**：面试官语音播报题目，同时在界面同步显示文字
3. **回答**：你通过麦克风作答，系统实时记录回答内容
4. **反馈**：每题结束后展示参考答案和即时点评
5. **追问/下一题**：根据策略随机追问或继续下一题
6. **最终报告**：整场结束后生成详细报告，涵盖评分、薄弱点、风险点和训练建议

---

## 报告内容预览

完成拟真面试后，系统会生成一份详细报告，包含以下部分：

| 报告模块 | 内容 |
|----------|------|
| 总分与整体评价 | 综合评分、技术深度、表达沟通、简历证据维度评分 |
| 每题评分 | 每道题的得分、标签和详细点评 |
| 薄弱点与提升方向 | 数据量化、角色描述、证据引用等薄弱环节 |
| 可能编造风险 | 标注回答中缺乏简历数据支撑的内容 |
| 推荐补练方向 | 专项训练建议，如数据量化训练、STAR 表达训练 |

## 与普通训练模式的区别

| 维度 | 普通训练 | 拟真面试 |
|------|----------|----------|
| 流程 | 逐题练习，自由节奏 | 完整面试流程，AI 控制节奏 |
| 提问方式 | 手动输入或选择题目 | AI 面试官主动提问 |
| 回答方式 | 文字输入或语音 | 语音作答为主 |
| 反馈 | 每题可选点评 | 每题即时反馈 + 整场报告 |
| 评分 | 可选 | 系统自动评分 |

## 常见问题

**Q：拟真面试会消耗 Token 吗？**
A：会。每次面试官提问和报告生成都需要调用 AI 模型，会产生 Token 消耗。建议在配置中选择合适的模型以控制成本。

**Q：可以用文字回答吗？**
A：当前设计以语音作答为主。文字回答的兼容支持将在后续版本中加入。

**Q：拟真面试和模拟训练有什么关系？**
A：拟真面试是模拟训练的一种增强模式。你可以在训练页面中切换普通模式和拟真面试模式。

**Q：报告可以保存吗？**
A：报告可以保存到会话记录，也可以导出为 MD 或 Word 格式（功能正在接入中）。
