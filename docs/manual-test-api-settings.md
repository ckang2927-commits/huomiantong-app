## 6. 通用行为

### 保存状态
- [ ] 修改任意字段后显示"有未保存修改"
- [ ] 保存后显示"保存成功"
- [ ] 保存后状态消失

### 启用/禁用
- [ ] 每个提供商有启用/禁用开关
- [ ] 禁用后该模型在面试台不可用
- [ ] 重新启用后可正常使用

### 金额预算
- [ ] 各提供商可独立设置金额预算
- [ ] 预算保存后用量面板显示对应金额
- [ ] 预算达到上限后有提示

### 错误提示
- [ ] 测试连接 401：提示 Key 无效
- [ ] 测试连接 402：提示余额不足
- [ ] 测试连接 403：提示没有模型权限
- [ ] 测试连接 429：提示请求太频繁
- [ ] 网络超时：提示检查网络和代理
