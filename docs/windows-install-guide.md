# Windows 安装与未知发布者说明

> 适用场景：给朋友或自己安装打包后的获面通 App（.exe 安装包）。
> 注意：因为不是微软商店应用，也没有购买代码签名证书，安装时 Windows 会提示"未知发布者"，这是正常现象。

---

## 1. 为什么会出现"未知发布者"

- 我们没有购买代码签名证书（每年约 $200-500），因此 Windows 无法验证安装包的发布者身份。
- 这**不代表**安装包有病毒或危险，只是 Windows 无法确认"这是谁开发的"。
- 所有获面通的源代码都是可见的，安装包由本地 `electron-builder` 生成，不含任何恶意代码。

## 2. 如何安全安装

### 方法一：直接运行（遇到 SmartScreen 拦截）

1. 双击安装包 `.exe` 文件。
2. Windows SmartScreen 可能会弹出"Windows 已保护你的电脑"提示。
3. 点击 **"更多信息"**（蓝色链接）。
4. 点击 **"仍要运行"** 按钮。
5. 如果弹出"用户账户控制"，点击 **"是"**。

### 方法二：如果 SmartScreen 直接阻止

1. 右键点击安装包文件。
2. 选择 **"属性"**。
3. 在 **"常规"** 选项卡底部，勾选 **"解除锁定"**。
4. 点击 **"确定"**。
5. 再次双击安装包即可正常安装。

### 方法三：给朋友的口头说明

可以直接告诉朋友：
> "这个安装包是我自己打包的，没有经过微软商店认证，所以 Windows 会提示'未知发布者'。点击'更多信息 → 仍要运行'就能正常安装了。不放心的可以先查一下杀毒软件。"

## 3. 安装后首次启动

- 安装完成后，桌面和开始菜单会有获面通的快捷方式。
- 首次启动可能比平时慢几秒（因为 Windows 正在验证应用）。
- 如果 Windows Defender 弹出警告，选择 **"仍要运行"**。
- 启动后第一件事：配置 API Key（DeepSeek / 阿里 / OpenAI / Deepgram）。

## 4. 杀毒软件误报处理

极少数情况下，某些杀毒软件可能会误报 Electron 应用：

- **Windows Defender**：通常不会误报，如果出现，点击"允许"即可。
- **360 / 腾讯管家等**：可能报"未知文件"，添加信任区即可。
- **原因**：Electron 应用结构特殊（包含 Node.js 运行时），有些杀毒软件会误判。

## 5. 卸载方式

- 打开 **设置 → 应用 → 应用和功能**。
- 找到 **获面通**，点击 **卸载**。
- 注意：卸载不会删除 `%APPDATA%/huomiantong/` 目录下的数据。如需彻底清除，需手动删除该目录。

## 6. 常见问题

| 问题 | 解决 |
|------|------|
| 安装包打不开，无反应 | 右键 → 属性 → 解除锁定 |
| SmartScreen 拦截后没有"仍要运行" | 使用方法二解除锁定 |
| 杀毒软件删除安装包 | 添加信任区后重新下载 |
| 安装后应用闪退 | 检查是否满足 Windows 10 1809+ |
| 提示缺少 DLL | 安装 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) |

> 安全提示：请从可信来源获取安装包，核对文件大小和版本号。
