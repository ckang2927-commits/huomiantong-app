# 获面通：用量预算案例库

> 最后更新：2026-07-22  
> 说明：以下是预算规划思路，不是官方价格承诺。实际费用以服务商官网和账单为准。

## 5-10 元预算：先体验，不焦虑

适合：

- 配置 API 后先试试软件
- 偶尔生成几道面试回答
- 少量模拟训练

建议：

- 默认选 fast/flash 类模型
- 回答风格选短答或标准回答
- 先不要做大量预热缓存
- 语音转写只在需要时打开

## 20-50 元预算：日常练习够用

适合：

- 每周多次模拟面试
- 经常导入简历和 JD 调整回答
- 做 10/15/20 题训练

建议：

- 日常用低价模型，重要问题再切高质量模型
- 给每个服务商单独设置预算
- 每周看一次设置页里的估算用量
- Deepgram 余额单独去后台看，不只看获面通

## 50-100 元预算：集中备面

适合：

- 短期内准备多场面试
- 需要频繁训练、复盘、导出
- 会使用预热缓存和模拟训练

建议：

- 先把简历和 JD 整理好，减少重复生成
- 预热缓存只给目标岗位生成，不要每个岗位都生成一遍
- 重要面试前做一次作战室检查
- 打开预算上限，避免连续训练时忘记控制费用

## 混合模型使用建议

| 场景 | 推荐策略 |
|---|---|
| 日常模拟 | fast/flash 模型 |
| 简历润色和复杂项目解释 | pro/max/高级模型 |
| 英文面试或复杂推理 | OpenAI / Claude 等高质量模型 |
| 语音实时转写 | Deepgram，按需开启 |

## 不建议的用法

- 不看预算，连续生成大量超长答案
- 简历材料没整理好就反复让 AI 重写
- 语音转写一直开着不关
- 每个模型都开预算但不清楚哪个模型正在使用
- 把软件估算金额当成最终账单

## 更多预算案例

### 案例 4：日常轻度使用（省钱方案）

**使用习惯**：每周 2 次面试模拟，每次约 20 分钟，使用 DeepSeek Chat 模型。

| 项目 | 估算 |
|------|------|
| 每次 Token 消耗 | 约 8,000 Token（输入 5K + 输出 3K） |
| 每次费用 | 约 ¥0.04（DeepSeek Chat ¥5/1M Token） |
| 每周费用 | 约 ¥0.08 |
| **每月费用** | **约 ¥0.32** |

> 💡 只使用 DeepSeek Chat，每月花费不到 1 元，适合预算敏感的用户。

---

### 案例 5：高频面试备战（标准方案）

**使用习惯**：每天 1 次模拟训练 + 实时面试辅助，使用 DeepSeek Chat 为主。

| 项目 | 估算 |
|------|------|
| 每天 Token 消耗 | 约 50,000 Token（含训练和实时辅助） |
| 每天费用 | 约 ¥0.25 |
| **每月费用** | **约 ¥7.50** |

> 💡 如果每周有 2-3 天使用 GPT-4o-mini 做深度分析，每月额外增加约 ¥5-10。

---

### 案例 6：深度面试准备（重度和混合方案）

**使用习惯**：每天高强度训练 + 实时面试辅助，混合使用 DeepSeek Chat 和 GPT-4o-mini。

| 项目 | 估算 |
|------|------|
| 每天 DeepSeek Chat | 约 80,000 Token → ¥0.40 |
| 每天 GPT-4o-mini | 约 20,000 Token → ¥0.30 |
| 每天 Deepgram 转写 | 约 60 分钟 → $0.12（约 ¥0.87） |
| **每月费用** | **约 ¥47**（模型 ¥21 + Deepgram ¥26） |

> ⚠️ 重度使用时 Deepgram 转写费用可能超过模型费用。注意 Deepgram 免费额度（$200/月）用完后会按量计费。

---

### 案例 7：纯语音转写（不用 AI 回答）

**使用习惯**：只使用语音转写功能记录面试内容，不生成 AI 回答。

| 项目 | 估算 |
|------|------|
| 每次面试转写 | 约 45 分钟音频 |
| 每次 Deepgram 费用 | 约 $0.09（¥0.65） |
| 每周 3 次面试 | 约 ¥1.95 |
| **每月费用** | **约 ¥7.80** |

> 💡 不需要 AI 回答时可以关闭回答模型，只保留 Deepgram 转写，费用更低。

### 省钱技巧总结

| 技巧 | 说明 |
|------|------|
| 优先使用 DeepSeek Chat | 性价比最高的回答模型 |
| 控制训练题数 | 10 题训练比 20 题省一半 Token |
| 设置月度预算上限 | 在设置中配置月度预算，超限后自动停止 |
| 利用 Deepgram 免费额度 | 新账号有 $200 免费额度，可用较长时间 |
| 不需要时关闭语音转写 | 节省 Deepgram 费用 |
| 定期查看用量面板 | 了解实际消耗，及时调整策略 |
