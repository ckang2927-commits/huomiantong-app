# 工作细节问题清单

> 面试中关于日常工作方式、团队协作、工具链的细节问题。
> 这些题面试官用来判断你"能不能直接上手干活"。

---

## 部门与团队

| 问题 | 准备方式 |
|------|----------|
| 你所在部门叫什么？负责什么？ | 如实回答 |
| 部门有多少人？怎么分工的？ | 如实回答 |
| 你的直属上级是什么角色？ | 如实回答 |
| 团队之间怎么协作的？ | 描述日常配合流程 |
| 你们部门和其他部门怎么对接？ | 描述跨部门协作方式 |

## 汇报与沟通

| 问题 | 准备方式 |
|------|----------|
| 你怎么向老板汇报工作？ | 日报/周报/例会频率和方式 |
| 老板对你的管理方式是什么样的？ | 自由/指导/结果导向 |
| 你怎么处理和产品/运营的需求？ | 需求评审/优先级排序 |
| 跨团队沟通中遇到冲突怎么办？ | 以数据和事实为准 |
| 你多久和老板做一次 1-on-1？ | 如实回答 |

## 会议与日程

| 问题 | 准备方式 |
|------|----------|
| 你一天一般开几次会？ | 如实回答 |
| 有什么站会/周会/月度会？ | 描述节奏 |
| 会议一般讨论什么？ | 进度同步/问题讨论/决策 |
| 你觉得你们会议效率怎么样？ | 可以说好也可以说改进空间 |
| 有没有太多不必要的会议？ | 坦诚但不要抱怨 |

## 工具与方法

| 问题 | 准备方式 |
|------|----------|
| 你日常用什么数据分析工具？ | SQL/Python/BI 工具 |
| 你们做实验用什么平台？ | 内部平台/A/B 测试框架 |
| 数据存在哪里？怎么查的？ | 数仓/离线/实时 |
| 你们用版本控制吗？ | Git 或其他 |
| 项目管理用 Jira 还是其他？ | 如实回答 |

## 项目流程

| 问题 | 准备方式 |
|------|----------|
| 一个典型项目从需求到上线怎么走？ | 描述完整流程 |
| 你们做不做代码审查？ | 如实回答 |
| 测试流程是怎样的？ | 自测/QA/自动化 |
| 上线/发布流程是怎样的？ | 灰度/全量/回滚 |
| 项目延期了怎么办？ | 沟通/排优先级/加班 |

## 关键指标

| 问题 | 准备方式 |
|------|----------|
| 你平时最关注哪些指标？ | 根据岗位说核心指标 |
| 这些指标怎么定义的？ | 要说得清楚口径 |
| 指标的波动范围一般多大？ | 正常波动/异常阈值 |
| 你怎么判断一个改动是正向的？ | 实验/显著性检验 |
| 有没有指标虚高或虚低的情况？ | 数据质量排查经验 |

## 准备思路

1. 每个问题挑一个真实经历准备，不要编
2. 用 STAR 法则组织：背景 → 任务 → 行动 → 结果
3. 答完可以反问面试官："你们这边是怎么做的？"
