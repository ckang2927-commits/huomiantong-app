# 获面通 v0.1.4 更新说明

发布日期：2026 年 8 月 4 日

这次是从 v0.1.3 到当前开发进度的正式发布版本。重点把新手引导、更新日志、面试台定位、复盘稳定性和本地回归能力一起补齐，让老用户可以直接在软件里检查并更新。

## 这次新增了什么

### 1. 漫游式新手引导

新手教程改成 21 步的页面内漫游引导：

- 目标区域会被高亮，页面其他区域禁止误点。
- 每一步都有“快速了解”和“详细说明”。
- 只保留“下一步”和“跳过引导”，老用户可以直接关闭。
- 设置中心可以重新打开教程。

面试台部分新增重点讲解：

- 当前候选人
- 目标岗位
- 实时转写
- AI 建议回答
- 回答策略
- 语音设置
- 面试预热题目

### 2. 面试台定位更清楚

- 点击“当前候选人”会跳到简历库的“姓名”字段并闪烁定位。
- 点击“目标岗位”会跳到简历库的“目标岗位”字段并闪烁定位。
- 点击顶部 Deepgram 状态会跳到“语音转写”配置区域。
- 点击顶部 DeepSeek / 当前回答模型状态会跳到对应 API 模型卡片。

### 3. 设置中心新增独立更新日志

“更新日志”已从诊断模块中独立出来，放在设置目录里：

- 可以查看历代版本发布时间和更新内容。
- 可以查看本次版本完整说明。
- “检查更新”只检查新版本，不会自动下载。
- 发现新版本后，需要用户确认才下载。
- 下载完成后，再由用户确认是否重启安装。

### 4. 新手配置体验更完整

- 设置页新增新手任务进度，帮助用户知道还差哪些步骤。
- API 模型配置增加 DeepSeek 等服务商的说明、配置顺序和测试反馈。
- 语音转写配置更清楚地区分服务商、Key、麦克风和电脑音频。
- 帮助中心索引已刷新，能搜索到最新教程和回归记录。

## 优化和修复

- 修复连续问题回答队列的顺序问题，上一题结束后会继续处理下一题。
- 强化简历 RAG 深度检索，本地回归覆盖多候选人、上一家公司、RFM、漏斗和项目证据命中。
- 面试复盘增加本地回归，覆盖问题提取、回答切片、质量评分和导出。
- AI 深度报告和 AI 深度话术在无 Key 或模型失败时会回退本地草案，不让页面空白。
- 长录音复盘增加分段、超时、漏题和失败重试提示。
- 拟真面试题库、难度、侧重点和已用题排除逻辑通过本地回归。
- 发布资源检查确认三套本地面试官声音和 Piper 运行文件会进入安装包。

## 保留内容

升级不会删除以下本地数据：

- API Key 和模型设置
- 候选人简历
- 历史会话
- 模拟训练记录
- 面试复盘记录
- 预算和用量记录
- 三套本地面试官声音
- 500 道数据分析师题库

## 已知情况

- 当前 Windows 安装包仍未购买代码签名证书，首次安装或更新时可能显示“未知发布者”。
- 离线语音模型会让安装包体积较大，这是为了让拟真面试声音尽量不依赖网络。
- 语音转写仍需要用户自己配置 Deepgram 或其它已接入的语音服务 Key。
- 国内语音服务商更完整的接入本轮先暂停，不作为 v0.1.4 发布内容。

## 升级方式

旧版本用户可以在：

`设置 → 更新日志`

点击“检查更新”。发现 v0.1.4 后，先点击“下载更新”，下载完成后再点击“重启安装”。

也可以直接下载新的安装包覆盖安装。覆盖安装不会删除 `%APPDATA%/huomiantong/` 中的用户数据。
