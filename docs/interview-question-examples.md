# 获面通：岗位题库样例文档

> 按岗位列出的常见面试题示例。

## 数据分析岗

1. 请介绍一个你最近的数据分析项目。
2. 如果业务方质疑你的结论，你会怎么处理？
3. 请展开讲讲指标体系建设。
4. 你在 SQL 优化或数据清洗中遇到过什么难题？
5. 怎么评估一个 A/B 实验的结果是否可信？

## AI 产品经理岗

1. 请介绍一个你负责的 AI 产品或功能。
2. 你怎么判断一个场景适不适合用 AI 解决？
3. 模型输出有幻觉时，你怎么做产品层面的风控？
4. 你怎么定义和评估 AI 产品的用户体验？
5. RAG 产品的知识库、召回和评估怎么看？

## 前端工程师岗

1. 你做过最复杂的前端组件是什么？
2. 项目里做过哪些性能优化？
3. React/Vue 的渲染机制了解多少？
4. 怎么保障前端项目的可维护性？
5. 线上遇到了兼容性问题怎么排查？

## 全栈工程师岗

1. 你完整负责过的全栈项目是什么样的？
2. 接口设计时你怎么考虑异常和幂等？
3. 数据库表结构设计有什么取舍？
4. 项目访问变慢怎么从全链路排查？
5. 怎么保障上线稳定性？

## 后端开发岗

1. 你设计过的最复杂的接口是什么？
2. 数据库索引怎么设计和优化？
3. 哪些场景适合用缓存？穿透/雪崩怎么处理？
4. 线上接口变慢或报错率升高怎么排查？
5. 怎么设计高可用系统？

## 压力面

1. 你这个经历听起来比较泛，有没有只有亲自做过才知道的细节？
2. 没有数据证明，你怎么证明你的贡献？
3. 你的个人贡献和团队贡献怎么区分？
4. 如果这段经历被认为不匹配，你怎么回应？
5. 讲一次判断失误的经历和复盘。

## 前端开发岗

1. 你觉得 React 和 Vue 在设计理念上最大的区别是什么？
2. 如果页面加载超过 3 秒，你会从哪些方面优化？
3. 讲一个你做过的最复杂的前端组件。
4. 前端项目的代码质量怎么保证？
5. 你了解哪些前端安全攻击？怎么防范？

## 全栈开发岗

1. 让你设计一个问卷系统，从前端到后端你怎么搭？
2. 前后端联调时接口改了但前端不知道，你怎么避免这种情况？
3. 你会怎么设计 RESTful API 的版本管理？
4. 用户上传文件后后端怎么处理？前端怎么给进度反馈？
5. 如果线上出了 Bug，从报警到修复你是什么流程？

## 后端开发岗

1. 让你设计一个短链接服务，数据库表怎么设计？
2. 接口响应变慢了，你从哪些方面排查？
3. 多个服务之间的数据一致性怎么保证？
4. 你会怎么设计一个限流方案？
5. 第三方接口挂了，你的系统怎么做兜底？

## HR 综合面

1. 用一句话介绍你自己。
2. 你觉得自己最大的优点和缺点是什么？
3. 三年内你有什么职业规划？
4. 你最近一次和别人意见不合是怎么处理的？
5. 如果这次面试没过，你会怎么想？
6. 除了专业能力，你觉得你能给团队带来什么？
7. 你做过最让你自豪的一件事是什么？
8. 你比较不能接受什么样的工作环境或团队？
9. 为什么你从上一家公司离职？
10. 你面试其他公司了吗？进行到什么阶段了？
