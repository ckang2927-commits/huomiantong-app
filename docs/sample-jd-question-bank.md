# 示例 JD 与问题库

> 用途：提供可直接复制使用的岗位 JD 和面试问题，用于演示、模拟训练和模板预设。
> 注意：所有 JD 为示例用途，实际招聘请以目标公司官方发布为准。

---

## 一、数据分析岗

### 示例 JD

```
岗位名称：数据分析师
所属部门：数据部
工作地点：远程/上海

岗位职责：
1. 负责业务线日常数据监控，搭建核心指标看板和自动化报表
2. 设计并分析 A/B 实验，为产品迭代提供数据驱动的决策建议
3. 深入分析用户行为、留存、转化等核心链路，定位增长机会
4. 与产品、运营、市场团队协作，输出专题分析报告

任职要求：
1. 2 年以上数据分析经验，统计学/数学/计算机相关专业优先
2. 精通 SQL，熟悉 Python 或 R 进行数据处理和可视化
3. 熟悉 A/B 实验设计原理和统计推断方法
4. 良好的业务理解力和沟通能力
5. 有用户增长或电商分析经验者优先
```

### 面试问题

**基础类**
- 请做 1 分钟自我介绍。
- SQL 中窗口函数有哪些常用场景？举例说明。
- Python 中处理缺失值的方法有哪些？各有什么适用场景？

**项目类**
- 讲一个你通过分析推动业务决策的案例。
- 如果发现某核心指标突然下跌 20%，你怎么排查原因？
- 如何评估一个实验的效果？如果结果不显著怎么办？

**场景类**
- 运营说"用户活跃度下降了"，你怎么定义和拆解这个问题？
- 如何衡量一个推荐系统的效果？你会关注哪些指标？
- 数据口径不一致导致两个部门数据对不上，怎么解决？

## 二、AI 产品岗

### 示例 JD

```
岗位名称：AI 产品经理
所属部门：产品中心
工作地点：北京/杭州

岗位职责：
1. 负责 AI 产品的需求分析、产品规划和路线图制定
2. 深入理解大模型能力边界，设计合理的 AI 功能和交互方式
3. 管理训练数据 pipeline，与标注团队协作优化数据质量
4. 制定模型效果评估标准，推动产品持续迭代

任职要求：
1. 3 年以上产品经理经验，1 年以上 AI 或对话类产品经验
2. 了解 NLP/大模型基本概念，能和技术团队有效沟通
3. 数据驱动，能独立设计评估指标和分析框架
4. 优秀的跨团队协作能力
```

### 面试问题

**基础类**
- AI 产品经理和传统产品经理的最大区别是什么？
- 你怎么评估一个 AI 功能该不该做？
- 什么是"人机协作"的产品设计思路？

**项目类**
- 讲一个你参与的 AI 产品项目，从需求到上线的完整过程。
- 模型输出的内容质量不稳定，你怎么设计兜底策略？
- 如何处理用户对 AI 回答的负面反馈？

**场景类**
- 产品上线后用户反馈 AI 回答"太机械"，怎么改进？
- 如何决定用大模型 API 还是自建小模型？
- 标注团队反馈标注指南不清晰，你怎么迭代？

## 三、前端开发岗

### 示例 JD

```
岗位名称：前端开发工程师
所属部门：技术部
工作地点：远程/深圳

岗位职责：
1. 负责 Web 应用的前端开发和性能优化
2. 参与组件库建设和维护，提升团队开发效率
3. 与后端、设计协作，高质量还原 UI 和交互
4. 关注前端技术趋势，推动技术升级

任职要求：
1. 2 年以上前端开发经验
2. 精通 React 或 Vue，熟悉 TypeScript
3. 理解浏览器渲染原理和前端性能优化
4. 良好的代码规范和工程化意识
5. 有组件库或工具链开发经验者优先
```

### 面试问题

**基础类**
- React 中 useState 和 useReducer 的区别，什么场景用哪个？
- CSS 中 BEM 命名规范的好处是什么？
- 前端模块化标准（CommonJS / ESM）的区别？

**项目类**
- 讲一个你做过的性能优化案例，具体做了什么、效果如何。
- 如果你是项目前端负责人，怎么保证代码质量？
- 如何设计一个支持主题切换的组件库？

**场景类**
- 页面白屏了，你怎么排查原因？
- 一个列表页有 1 万条数据，怎么渲染不卡？
- 如何向后端"推销"GraphQL 或新的 API 方案？

## 四、全栈开发岗

### 示例 JD

```
岗位名称：全栈开发工程师
所属部门：研发部
工作地点：远程

岗位职责：
1. 负责产品前后端功能开发和维护
2. 参与系统架构设计和技术方案评审
3. 编写单元测试和集成测试，保障代码质量
4. 参与代码审查，推动团队技术成长

任职要求：
1. 3 年以上全栈或后端开发经验
2. 熟悉 React/Vue + Node.js/Python 技术栈
3. 理解 RESTful API 设计和数据库设计
4. 有 docker 部署和 CI/CD 经验者优先
```

### 面试问题

**基础类**
- 你会怎么设计一个短链接服务的后端架构？
- 什么是 RESTful API 的设计原则？
- 数据库索引什么时候会失效？

**项目类**
- 讲一个你从 0 到 1 搭建的项目。
- 如果线上出现性能问题，你从哪些方面排查？
- 如何处理前后端联调中的接口变更问题？

**场景类**
- 产品需求说"这个功能下周上线"，但你觉得时间不够，怎么沟通？
- 老项目技术债太重，你选择重构还是渐进式优化？为什么？
- 如何保证接口的幂等性？

## 五、后端开发岗

### 示例 JD

```
岗位名称：后端开发工程师
所属部门：后端技术部
工作地点：杭州

岗位职责：
1. 负责后端服务的开发和维护
2. 参与系统设计和数据库方案评审
3. 编写高质量的代码和单元测试
4. 参与线上问题排查和性能优化

任职要求：
1. 2 年以上后端开发经验
2. 熟悉 Java/Python/Go 至少一门语言
3. 理解分布式系统基本概念
4. 有微服务或消息队列使用经验者优先
```

### 面试问题

**基础类**
- CAP 理论怎么理解？实际系统中你怎么权衡？
- 什么情况下用 NoSQL 而不是 MySQL？
- 如何设计一个高可用的接口？

**项目类**
- 讲一个你解决过的线上事故。
- 如何保证多个服务之间的数据一致性？
- 你做过哪些性能优化？效果如何？

**场景类**
- 接口突然变慢，你怎么定位瓶颈？
- 第三方服务挂了，你的系统怎么兜底？
- 如何评估一个系统能不能支撑双十一流量？

## 六、压力面 / 行为面

这些问题不依赖具体技术栈，适合模拟压力场景：

1. 你最近一次和同事意见不合是什么事？怎么处理的？
2. 如果项目中你发现方案有问题但已经做了一半，怎么办？
3. 你觉得自己最大的弱点是什么？
4. 你过去一年最后悔的一个决定是什么？
5. 如果给你 30 天做一个新项目，你怎么规划？
6. 你如何保持学习和成长的节奏？
7. 你理想的工作环境是什么样的？
8. 你上次没完成目标是什么原因？

## 使用方式

- 复制 JD 到简历库的"岗位 JD"编辑框
- 使用问题作为模拟训练的出题素材或面试台手动输入
- 问题按难度分级：基础（适合热身）、项目（适合深挖）、场景（适合考察应变）
