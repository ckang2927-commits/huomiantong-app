## 仍需用户配合的真实验收

1. 麦克风连续说 2-3 个问题，确认无关语气词不会触发回答。
2. 开启转写后点击暂停，说一段话，确认不会进入会话；恢复后再说问题，确认可以继续识别。
3. 用真实口音/误识别样本测试“低价公司/第一家公司”等纠错。
4. 连续问多个问题，确认第一问先出答案，后续问题进入队列，右侧可以切换“待生成”。
5. 如果要验腾讯云 STT，需要填写真实 `AppID|SecretId|SecretKey`，再测试麦克风/电脑音频转写。
