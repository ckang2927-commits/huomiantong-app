# 获面通：模拟训练使用指南

> 刷题练习，AI 点评，持续进步。

## 开始训练

1. 点击左侧导航栏的"模拟训练"
2. 选择训练模板（数据分析/AI 产品/前端/全栈/后端/压力面）
3. 选择题目数量（10/15/20）
4. 点击"开始训练"

## 回答问题

- 输入回答后提交，AI 给出点评和分数
- 可开启"语音作答转写"用麦克风口述
- 右侧显示参考答案（基于你的简历和 JD）

## 错题与复盘

- 低于 75 分的题自动进入错题收藏夹
- 完成全部题目后生成最终复盘报告
- 查看薄弱点排行榜和专项训练入口
- 成绩趋势显示多轮训练走势

## 保存与导出

- 训练结果可保存到会话记录
- 支持导出 MD 和 Word 格式
