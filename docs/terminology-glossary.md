# 获面通：产品术语表与统一叫法

> 统一软件内外的名词叫法，避免混淆。

## 页面/功能

| 标准术语 | 英文 | 说明 | 不要叫 |
|---------|------|------|-------|
| 面试台 | Workspace | 实时问答的主页面 | 面试页、主页面 |
| 模拟训练 | Training | 刷题练习模块 | 训练页、练习模式 |
| 作战室 | Checkup | 面试前体检页面 | 体检页、健康检查 |
| 简历库 | Resume | 候选人简历管理 | 简历页、个人信息 |
| 设置 | Settings | 全局配置页面 | 设置页、API 设置 |
| 会话记录 | Sessions | 历史数据查看 | 历史记录、历史会话 |

## 功能/概念

| 标准术语 | 英文 | 说明 |
|---------|------|------|
| 候选人 | Candidate | 面试者/求职者 |
| 正式简历 | Formal Resume | 1-2 页浓缩简历 |
| 万字简历 | Detailed Resume | 详细经历解释版 |
| 预热缓存 | Warmup Cache | 提前缓存的答案 |
| 悬浮窗 | Floating Window | 独立问答展示窗口 |
| 诊断日志 | Diagnostic Log | 错误和异常记录 |
| 隐私模式 | Privacy Mode | 脱敏显示模式 |
| 固定题纲 | Question Outline | 训练模板中的预设题目 |

## 按钮/操作

| 标准术语 | 说明 |
|---------|------|
| 生成回答 | 触发 AI 回答问题 |
| 保存设置 | 保存当前配置修改 |
| 测试连接 | 验证 API Key 有效性 |
| 保存会话 | 保存当前面试记录 |
| 开始训练 | 启动模拟训练 |
