# 问题队列本地回归记录

最后更新：2026-08-03

## 覆盖目标

这份回归用于验证面试台在连续收到多个面试问题时，不会丢题、乱序或卡在上一题。

## 自动验收

命令：

```bash
npm run validate:queue
```

当前结果：6/6 通过。

## 已覆盖场景

- 空闲状态收到第一题时，直接进入生成中，不额外进入队列。
- 当前答案生成中收到第二题、第三题时，按 FIFO 顺序排队。
- 第一题完成后自动继续第二题，第二题完成后自动继续第三题。
- 缓存答案命中后，也会继续取出下一道排队问题。
- 开始新会话或重置回答状态时，当前题和待生成队列会清空。
- 排队项保留 `id`、`question`、`transcript`，支撑右侧“待生成”标签和历史/待生成切换。
