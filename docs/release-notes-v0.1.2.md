# 获面通 v0.1.2 更新说明

发布日期：2026 年 7 月 31 日

这次更新重点优化了拟真面试和模拟训练，也把新手第一次使用时最容易卡住的步骤整理成了文档。

## 这次新增了什么

### 1. 拟真面试支持三套本地离线声音

在“拟真面试”的面试官声音下拉框中，现在可以选择：

- 小雅：女声，柔和
- 华妍：女声，清晰
- 朝文：男声，沉稳

每套声音旁边都有“试听”按钮。选择后，面试官提问会优先使用对应声音朗读。声音文件已经随安装包提供，正常情况下不依赖网络；如果本地声音播放失败，软件会自动回退到系统语音。

### 2. 模拟训练接入 500 道数据分析师题库

模拟训练内置了 500 道通用数据分析师面试题，覆盖：

- 业务分析与指标体系
- SQL 与数据处理
- 实验分析与归因
- 统计、模型与数据质量
- 项目经历、沟通协作和复盘
- 难点处理、估算、优先级和业务落地

训练会根据岗位模板、难度和题目方向动态抽取，不是每次都固定问同一组题。题目和参考答案也保留在本地项目文档中，便于后续继续整理和扩充。

### 3. 模拟训练回答记录更方便

- 回答框支持手动输入和修改回答记录。
- 参考答案可以展开查看，也可以先隐藏，避免直接影响自己的作答。
- 每题会记录点评、分数和训练表现，完成后可进行集中复盘。
- 语音作答时会保留口语表达相关信息，方便复查语速、停顿和表达结构。

## 优化和修复

- 优化拟真面试的声音选择、朗读和失败回退逻辑。
- 优化本地声音资源的打包方式，安装后即可使用。
- 优化模拟训练出题逻辑，减少问题固定、重复的问题。
- 优化帮助中心文档入口，增加新手教程和版本说明。
- 保留原有本地数据、简历、会话、复盘记录、预算记录和 API Key。

## 已知问题

- 安装包包含离线语音模型，文件体积会比旧版本更大，这是为了让声音不依赖网络。
- 当前 Windows 安装包没有购买代码签名证书，部分电脑第一次安装时可能显示“未知发布者”或触发 SmartScreen。确认安装包来自获面通发布页后，可点击“更多信息”→“仍要运行”。
- 本地离线声音主要用于拟真面试朗读，语音转写仍需要配置对应的语音转写服务。

## 如何更新

旧版本用户不需要重新找安装包：

1. 打开获面通，进入“设置”。
2. 找到“关于与诊断”，点击“检查更新”。
3. 有新版本时，软件会自动下载更新包。
4. 下载完成后点击“重启安装”。

更新只替换软件安装文件，不会覆盖 `%APPDATA%/huomiantong/` 中的本地数据。更新前仍建议先导出一次备份。

如果提示没有更新、找不到 `latest.yml` 或网络异常，通常是线上 Release 还没有发布完成，或者当前网络无法访问 GitHub Releases，请稍后重试。
