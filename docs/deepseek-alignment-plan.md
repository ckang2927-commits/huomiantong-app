## 本轮原则

1. 先修“功能假完成”和数据安全问题，再优化视觉。
2. 不再用“构建通过”代替功能验证。
3. 每项完成后必须写明：涉及文件、验证动作、验证结论。
4. 不修改用户既有简历、会话和 API 配置数据。
