# 薪资谈判安全边界文案

> 薪资谈判是面试中最敏感也最容易出问题的环节。
> 以下话术原则帮助你在不编造、不说死的前提下争取合理薪资。

---

## 核心原则

### 1. 不给精确数字
- ✅ "我的期望是 22-25K 左右"
- ❌ "我要 23,500"
- ✅ "我上家年薪大概 25 万出头"
- ❌ "我上家月薪 18,327"

### 2. 让对方先出价
- ✅ "我想先了解一下这个岗位的薪资范围"
- ❌ "我的期望是 XX"
- ✅ "薪资是我考虑的因素之一，但不是唯一"
- ❌ "低于 XX 我不去"

### 3. 不编造
- ✅ "我了解到的市场行情大概在这个范围"
- ❌ "我有另一个 offer 给到 XX"
- ✅ "如果薪资方面有差距，我也看重成长空间"
- ❌ "没有 XX 我不会考虑"

## 常见问题和话术

### 问："你的期望薪资是多少？"
```
"我对这个岗位很感兴趣，薪资方面我的期望是 22-25K 左右，
具体可以根据整体 package 和岗位情况再聊。
我更看重的是团队和技术成长空间。"
```

### 问："你上家薪资多少？"
```
"我上家年薪大概 25 万出头（含年终和奖金）。
具体月薪结构我不太方便透露，但整体水平是这样的。"
```

### 问："试用期薪资怎么算？"
```
"我了解行业一般是 80-90%，这个我可以接受。
我比较关心的是试用期的考核标准和转正流程。"
```

### 问："除了薪资还有什么要求？"
```
"希望五险一金能按规定缴纳，如果有补充医疗更好。
其他方面我比较灵活，主要是岗位匹配度优先。"
```

## 不建议说的内容

- ❌ 具体上家精确薪资（容易被压价或背景调查对不上）
- ❌ 最低接受薪资（先出价就输了）
- ❌ 对前公司薪资的抱怨（显得不专业）
- ❌ 虚构的 offer 数字（背调穿帮就没机会了）
- ❌ 详细家庭经济状况（与面试无关）

## 薪资谈判策略表

| 场景 | 建议策略 | 话术示例 |
|------|----------|----------|
| HR 先问期望 | 给范围，不给定点 | "22-25K 左右" |
| 被压价 | 问清楚总包再回应 | "除了月薪，年终和福利大概什么情况？" |
| 对方出价太低 | 表示差距 + 重申价值 | "和我的期望有些差距，但我也看重成长空间" |
| 有多轮面试 | 留到终面再谈 | "我想等全面了解岗位后再聊具体的" |
| 试用期薪资 | 接受标准比例，问转正条件 | "80-90% 可以接受，转正标准是怎样的？" |
