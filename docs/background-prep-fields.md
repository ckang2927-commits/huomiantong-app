## 7. 一致性检查包

| 字段 | 说明 |
|------|------|
| 冲突检测范围 | 跨资料包的相同字段（如薪资在不同包中不一致） |
| 冲突等级 | 高（不一致会影响面试）/ 中（建议统一）/ 低（可忽略） |
| 建议处理 | "替代旧值" / "保留旧值" / "合并说明" |
| 检查触发方式 | 手动点击"运行检查" |

## 来源标签映射

| 代码 | 显示标签 | 颜色 |

| `unverified` | 待确认 | 红色 |
