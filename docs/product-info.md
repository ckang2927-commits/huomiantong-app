> 版本：v0.1.0（开发版）  
> 更新日期：2026-07-21  
> 适用平台：Windows 10 / Windows 11（64 位）

---

## 产品概述

获面通是一款 Windows 桌面面试辅助工具，帮助求职者在模拟练习和真实面试中更从容地展示自己。

**核心理念**：本地优先、实时辅助、持续改进。

## 功能说明

### 面试台
实时转写面试官提问（支持麦克风和电脑音频），结合候选人的简历和岗位 JD，AI 实时生成回答建议。支持手动输入问题和自动转写触发两种模式。

### 模拟训练
预设 6 种面试模板（数据分析、AI 产品、前端、全栈、后端、压力面），支持自定义模板。每道题提交后获得 AI 点评和评分，完成后生成薄弱点分析和复盘报告。

### 简历库
管理多个候选人简历，支持 PDF / DOCX / MD 格式导入。支持正式简历、万字简历和补充材料，AI 回答基于简历内容提供依据来源。

### 会话记录
保存所有面试和训练会话，支持查看、重命名、按候选人筛选、导出 Markdown 或 Word。顶部看板自动统计高频题型和质量趋势。

### 作战室
面试前一键体检，检查候选人简历、模型配置、语音服务、悬浮窗和预热缓存是否就绪。

## 隐私说明

- **本地存储**：所有用户数据（设置、会话、训练成绩、用量）存储在本地计算机，不会自动上传到任何服务器。
- **API Key 加密**：API Key 使用操作系统安全存储（safeStorage）加密保存。
- **数据传输**：AI 回答仅发送到你配置的 API 服务商（DeepSeek / 阿里 / OpenAI / Anthropic）；语音转写仅发送到 Deepgram。获面通本身不会收集或传输这些数据。
- **隐私模式**：开启后，导出文档和悬浮窗中的候选人姓名、公司名等敏感信息会被自动替换。
- **日志数据**：诊断日志只存储在本地，不会上传。

## 数据存储位置

```
%APPDATA%/huomiantong/
```

包含设置文件、会话历史、训练成绩和用量统计。卸载前建议先导出备份。

## 网络依赖

获面通的部分功能需要网络连接：

| 功能 | 网络依赖 | 说明 |
|------|---------|------|
| AI 回答生成 | ✅ 必需 | 需配置 API Key 并联网 |
| 语音转写（Deepgram） | ✅ 必需 | 需配置 Deepgram Key 并联网 |
| 模拟训练 AI 点评 | ✅ 需要 | 无网络时进入本地兜底模式 |
| 备份导出/导入 | ❌ 不需要 | 纯本地文件操作 |
| 简历库管理 | ❌ 不需要 | 纯本地文件操作 |

## 技术架构

| 层级 | 技术 |
|------|------|
| 框架 | Electron + Vite |
