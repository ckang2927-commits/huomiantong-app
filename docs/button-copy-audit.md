## 8. 巡检规则

每次修改按钮文案时检查：
- [ ] 按钮文案是否 2-6 个字（不宜过长）
- [ ] 是否用动词开头（"生成回答"而非"回答生成"）
- [ ] 是否和术语表一致
- [ ] 同一功能在不同页面是否用同一文案
- [ ] 删除/危险操作是否有确认弹窗
