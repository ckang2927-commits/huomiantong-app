# 获面通新手教程

第一次使用获面通时，按下面的顺序操作即可完成一轮面试练习。

## 1. 安装软件

双击 `huomiantong-setup-x.x.x.exe`，按安装向导完成安装。安装完成后，从桌面快捷方式启动获面通。

如果 Windows 显示“未知发布者”或 SmartScreen：

1. 先确认安装包来自你信任的发布位置。
2. 点击“更多信息”。
3. 点击“仍要运行”。

这是因为当前安装包还没有购买 Windows 代码签名证书，不代表软件一定有问题。

## 2. 第一次打开先做两件事

### 配置回答模型

1. 点击左侧“设置”。
2. 在模型或提供商区域选择一个你能使用的服务商。
3. 填入对应 API Key。
4. 点击“测试连接”。
5. 测试成功后点击“保存设置”。

### 配置语音转写

如果你想把面试官说话自动转成文字：

1. 在设置中找到 Deepgram。
2. 填入 Deepgram API Key。
3. 点击“测试连接”。
4. 保存设置。

没有语音转写 Key 时，仍然可以手动输入问题，先体验 AI 回答和模拟训练。

## 3. 导入简历

1. 点击左侧“简历库”。
2. 新增候选人，填写姓名和应聘岗位。
3. 上传正式简历，支持 PDF、DOCX、MD 等常用格式。
4. 如果有更完整的项目经历，可以继续补充“万字简历”或其他材料。
5. 点击“保存简历”。

简历越真实、越完整，AI 越容易生成贴合个人经历的回答。不要把 API Key、身份证号等不必要的敏感信息放进简历材料。

## 4. 用面试台练习

1. 回到左侧“面试台”。
2. 在问题输入框里手动输入面试官的问题。
3. 点击“生成回答”，或使用页面提示的快捷键。
4. 查看等待话术、正式答案、简历依据和风险提示。
5. 面试结束后保存会话，方便以后复盘。

如果使用真实线上面试，可以在语音设置中选择麦克风转写，或者选择电脑音频转写来捕获面试官的系统声音。第一次使用语音前，先在 Windows 中允许获面通访问麦克风。

## 5. 用模拟训练刷题

1. 点击左侧“模拟训练”。
2. 选择岗位模板，例如“数据分析”。
3. 选择训练轮数。
4. 点击“开始训练”。
5. 看到题目后，先自己回答，再提交。
6. 查看点评、分数和参考答案。

模拟训练内置 500 道数据分析师题目，会按训练模板和题目方向动态抽取。建议先独立回答，再展开参考答案；这样复盘结果更接近真实面试表现。

回答框支持手动输入，也可以使用语音作答。完成一轮训练后，可以查看最终复盘和薄弱点。

## 6. 用拟真面试练习临场感

1. 点击左侧“拟真面试”。
2. 选择岗位、面试风格和题目数量。
3. 在“面试官声音”下拉框里选择声音。
4. 点击“试听”确认音色和音量。
5. 开始面试后，按正常面试节奏回答。

v0.1.2 提供三套本地离线声音：

- 小雅：女声，柔和
- 华妍：女声，清晰
- 朝文：男声，沉稳

这些声音随安装包一起安装，通常不需要联网即可朗读。若本地声音临时不可用，软件会尝试使用系统语音。

## 7. 保存、复盘和导出

- 面试台：保存会话后，在“会话记录”中查看。
- 模拟训练：完成训练后查看每题点评、参考答案和整体报告。
- 面试复盘：可以查看历史复盘记录，并导出 Markdown 或 Word。
- 导出前建议打开一次内容预览，确认姓名、公司和回答内容符合你的隐私要求。

## 8. 检查更新

旧版本升级步骤：

1. 进入“设置”。
2. 打开“关于与诊断”。
3. 点击“检查更新”。
4. 等待更新包下载完成。
5. 点击“重启安装”完成升级。

覆盖安装不会删除正常保存在 `%APPDATA%/huomiantong/` 中的 API Key、简历、会话和复盘记录。重要资料仍建议定期导出备份。

## 9. 常见问题

### 没有声音

先检查电脑音量、输出设备和系统静音状态，再点击“试听”。如果是语音转写没有文字，检查 Deepgram Key、麦克风权限和麦克风设备选择。

### AI 没有生成回答

进入设置测试回答模型连接，确认 API Key、模型名称和网络正常。简历没有导入时，部分功能会使用通用方法论回答。

### 模拟训练没有出题

先确认训练模板和题目数量已经选择，再检查回答模型是否配置成功。即使没有 API Key，软件也会提供本地兜底训练，但内容会更通用。

### 更新按钮提示失败

确认网络可以访问 GitHub Releases，并等待线上 Release 完成发布。看到“找不到 latest.yml”时，通常说明更新包还没有发布完整，不是本地数据损坏。

### 担心数据丢失

正常更新只替换安装目录中的程序文件，不会主动删除用户数据。更新前可以在设置里的备份功能导出一份备份，遇到异常时再恢复。

## 推荐使用顺序

`配置模型 → 导入简历 → 面试台试用 → 模拟训练刷题 → 拟真面试练临场 → 保存并复盘`
