# 背景资料补全中心

> 面试前准备的"第二张简历"——补充简历上没有的 HR、薪资、公司、工作细节和入职信息。
> 所有内容会标注来源和可信度，AI 模拟内容仅供参考，正式面试前建议自行确认。

---

## 模块定位

背景资料补全中心是面试台左侧的独立面板，用于在面试前一次性准备好简历之外的关键信息：

| 不要用它做什么 | 用它做什么 |
|---------------|------------|
| ❌ 替代正式简历和万字简历 | ✅ 补充简历里没有的 HR/薪资/公司背景 |
| ❌ 联网搜索最新公司新闻 | ✅ 记录已知的公司信息和待确认问题 |
| ❌ AI 自动生成全部内容 | ✅ 通过问答引导用户自己补全+AI 辅助模拟 |
| ❌ 保存到正式简历 | ✅ 生成后用户确认，保存到"其他简历" |

## 7 个资料包

| 资料包 | 覆盖内容 | 优先级 |
|--------|----------|:------:|
| HR 基础信息包 | 住址、通勤、学历、离职原因、空窗期、稳定性 | ★★★★★ |
| 薪资谈判包 | 期望薪资、上家薪资、涨幅、底薪、福利、试用期 | ★★★★★ |
| 公司背景包 | 主营业务、组织架构、岗位理解、行业竞品 | ★★★★☆ |
| 工作细节包 | 部门、汇报关系、协作方式、数据分析工具链 | ★★★★☆ |
| 进公司后勤包 | 工位、设备、社保、公积金、合同、试用期考核 | ★★★☆☆ |
| 风险回答包 | 简历冲突点、解释（黑话/人话）、绕过思路 | ★★★★☆ |
| 一致性检查包 | 跨资料包的字段冲突检测和标注 | ★★★☆☆ |

## 来源标签

每条生成的内容都会标注来源：

| 标签 | 含义 |
|------|------|
| 正式简历 | 内容来自你的正式简历 |
| 万字简历 | 内容来自你的万字/详细版简历 |
| 其他简历 | 内容来自你已保存的补充资料 |
| 用户填写 | 你手动填写的内容 |
| 公开资料 | 来自公司官网、招聘页面等公开信息 |
| AI 模拟参考 | AI 根据已知信息模拟的可能情况 |
| 待确认 | 尚未验证的信息，面试前建议检查 |

## 可信度等级

| 等级 | 图标 | 含义 | 面试建议 |
|------|:----:|------|----------|
| 高 | 🟢 | 来自简历或用户确认 | 可以直接用 |
| 中 | 🟡 | 来自公开信息或用户填写 | 建议复核后再用 |
| 低 | 🟠 | AI 模拟或推测 | 仅供准备思路，不要直接说 |
| 待确认 | 🔴 | 信息冲突或未验证 | 不要在面试中说死 |

## 使用流程

```
1. 选择资料包 → 2. 查看已有信息（来自简历）→
3. 补充填空（手动或 AI 辅助）→ 4. 检查来源和可信度 →
5. 确认内容准确 → 6. 保存到"其他简历"
```

## 重要原则

- **不把模拟当事实**：所有 AI 生成内容都标注"AI 模拟参考 / 低可信度"。
- **不说死**：涉及薪资、公司内部细节等敏感内容，建议用"我了解到...""据我了解..."等软表达。
- **不编造**：如果不知道，就标注"待确认"，不要在面试中硬说。
- **不透露**：HR 提问涉及隐私（具体住址、家庭情况）时，知道可以跳过或泛化回答。
