# DeepSeek 任务书：拟真面试模式基础建设

> 用途：这份任务书专门交给 DeepSeek 执行。目标是让 DeepSeek 先做低风险的 UI 初稿、文案、静态模板和验收脚本；不要触碰音频、AI、主进程、数据迁移等核心链路。

## 一、执行前必须阅读

1. `docs/product-optimization-backlog.md`
2. `docs/refactor-roadmap.md`
3. `docs/regression-checklist.md`
4. `docs/deepseek-safe-task-list.md`

## 二、绝对禁止修改

- 不修改 `src/main/**`
- 不修改 `src/preload/**`
- 不修改 Deepgram、麦克风、电脑音频采集逻辑
- 不修改 AI 回答生成、训练服务、RAG 检索、流式输出逻辑
- 不新增 npm 依赖
- 不改 API Key 保存、加密、备份恢复逻辑
- 不删除现有模拟训练功能

## 三、任务目标

在现有“模拟训练”基础上，先做“拟真面试模式”的低风险基础建设：

- 配置项清晰：面试时长、题目数量、难度、侧重点、面试官风格、追问策略。
- UI 像一个真实面试准备舱，而不是普通表单。
- 面试流程说明清楚：AI 面试官问、用户语音答、回答完显示参考答案、最后生成详细报告。
- 先做静态 UI 和文案，不接真实语音/AI 逻辑。

## 五、推荐 UI 内容

### 1. 配置区

- 面试时长：`10 / 20 / 30 / 45 / 60 分钟 / 自定义`
- 题目数量：`5 / 10 / 15 / 20 / 自定义`
- 难度：`简单 / 中等 / 偏难 / 压力面`
- 侧重点：`项目深挖 / 简历真实性 / 数据分析建模 / SQL与数据处理 / 业务理解 / HR综合`
- 面试官风格：`温和型 / 追问型 / 压力型 / 技术主管型 / HR型 / 随机`
- 追问策略：`固定走题 / 根据回答追问 / 随机混合`

### 2. 流程预览区

文案示例：

> 面试官会主动语音提问，并同步显示题目文字。你用麦克风回答后，系统会根据 3 秒沉默、结束语或“回答完毕”按钮判断本题结束。每题结束后展示参考答案和即时反馈，整场结束后生成详细报告。

### 3. 报告预览区

建议展示：

- 总分与整体评价
- 每题评分
- 回答结构问题
- 简历证据命中情况
- 可能编造风险
- 推荐补练方向
- 更优回答示例
