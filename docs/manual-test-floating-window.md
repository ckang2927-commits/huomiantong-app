## 1. 打开与关闭

### 打开悬浮窗
- [ ] 点击顶部悬浮窗按钮能打开悬浮窗
- [ ] 快捷键（如 Alt+H）能打开悬浮窗
- [ ] 打开后悬浮窗独立于主窗口，可拖动
- [ ] 多次点击不会打开多个窗口

### 关闭悬浮窗
- [ ] 点击关闭按钮（X）能关闭
- [ ] 最小化按钮能最小化到任务栏
- [ ] 再次点击打开按钮能恢复

## 2. 内容显示

### 问题与答案
- [ ] 显示当前面试问题
- [ ] 显示 AI 回答内容
- [ ] 显示回答依据来源（有简历时）
- [ ] 排队数量显示正确

### 同步更新
- [ ] 主窗口生成新答案后，悬浮窗自动更新
- [ ] 主窗口切换候选人后，悬浮窗信息同步
- [ ] 主窗口新会话后，悬浮窗内容清空

### 流式输出
- [ ] 生成中时悬浮窗显示流式内容
- [ ] 生成中显示"生成中..."状态
- [ ] 生成完成后内容完整

## 3. 交互操作

### 滚动与复制
- [ ] 内容过长时可滚动查看
- [ ] 可选中并复制文本
- [ ] 窗口调整大小时内容自适应

### 窗口状态
- [ ] 最大化/还原可用
- [ ] 窗口尺寸变化不应遮挡操作按钮
- [ ] 拖动窗口到屏幕边缘不会卡住

## 4. 多任务场景

- [ ] 悬浮窗打开时主窗口操作不受影响
- [ ] 主窗口关闭后悬浮窗也能独立工作
- [ ] 主窗口最小化后悬浮窗仍正常显示
- [ ] 主窗口重新打开后悬浮窗状态不丢失

## 5. 退出与恢复

- [ ] 关闭主应用时悬浮窗同步关闭
- [ ] 重新打开应用后悬浮窗功能正常
- [ ] 未生成答案时悬浮窗显示空状态
