# 帮助中心与本地文档搜索

## 1. 这个模块解决什么问题

帮助中心用于把 `docs/` 目录里已经沉淀的说明文档、排障文档、计划表和验收清单做成软件内可搜索入口。

用户遇到问题时，不需要去文件夹里翻几十个 `.md` 文件，可以直接在软件里搜索：

- `语音不能用`
- `402`
- `回答太长`
- `简历库`
- `拟真面试`
- `计划表`

## 2. 当前版本的搜索策略

当前版本采用本地文档优先策略：

1. 构建前自动扫描 `docs/*.md`。
2. 生成 `src/renderer/lib/generatedHelpDocs.ts`。
3. 搜索时先匹配文档标题。
4. 再匹配分类、关键词、常见问法、摘要、路径和正文片段。
5. 找不到完全命中时，给用户相似关键词建议。

这样做的好处是响应快、稳定、不会消耗 Token，也不会把用户的问题默认发到外部服务。

## 3. 当前覆盖范围

当前版本已经从手工维护升级为全量自动索引，覆盖 `docs/` 目录下所有 `.md` 文档。

维护方式：

- 新增或修改 `docs/*.md` 后，运行 `npm run docs:index`。
- `npm run build` 会自动先执行 `npm run docs:index`。
- 如果只是检查索引是否最新，运行 `npm run docs:index:check`。
- 生成文件是 `src/renderer/lib/generatedHelpDocs.ts`，不要手工修改。

## 4. 为什么暂时不默认联网搜索

帮助中心先不默认联网搜索，原因是：

- 很多问题和本地功能、历史改动、计划表有关，联网搜索反而不准。
- 用户可能会输入 API Key、简历内容、公司信息等敏感内容。
- 联网搜索会引入不稳定来源，需要额外做来源展示和隐私确认。

推荐后续升级方式：

1. 本地文档没有命中。
2. 用户点击“允许联网补充”。
3. 软件提示本次搜索会发送哪些关键词。
4. 搜索公开网页。
5. 结果只作为参考资料，不自动写入真实简历。

## 5. P3-4 已完成体验

2026-07-28 已把帮助中心升级成更像知识库的使用方式：

- 搜索结果展示正文片段，不只显示文档摘要。
- 搜索词在标题和片段中高亮，方便用户知道为什么命中。
- 结果卡片展示命中来源和相关度，例如标题、说明、正文、场景：语音转写。
- 支持收藏常用文档，收藏记录保存在浏览器本地 `localStorage`。
- 右侧固定高频文档入口，优先放 FAQ、语音排障、模型配置、预算、训练和总计划。
- 搜索无结果时给自然引导，不会默认联网，也不会自动把用户问题发出去。
- 增加轻量意图加权：搜索语音、API、简历、训练类问题时，优先展示对应主题文档。

验收用例：

- 搜索 `语音不能用`，优先命中 `docs/audio-troubleshooting.md` 和 `docs/audio-troubleshooting-guide.md`。
- 搜索 `402`，应能命中 API/错误码相关文档。
- 点击 `收藏` 后，顶部收藏数量增加，左侧“我的收藏”出现该文档。
- 点击 `打开文档` 后，应显示打开状态；打包版最终打开路径仍放到 P3-11 安装包专项验收。

## 6. 后续优化方向

- 支持 AI 根据本地文档生成解释。
- 支持把用户新问题沉淀成新的 FAQ。
- 支持联网补充公开资料，但必须有用户确认和来源记录。
- 支持更强的近义词归一，例如“话筒/麦克风”“余额/额度”“打不开/启动失败”。
- 支持把搜索日志以本地匿名方式统计成“用户最常问问题”。
