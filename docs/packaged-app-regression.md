# 打包后人工验收脚本

> 用途：安装 .exe 安装包后，按以下步骤逐项验收，确保打包版 App 功能正常。
> 前置条件：已安装完成，已配置至少一个 API Key（DeepSeek 或其他）。

---

## 1. 启动与主窗口

- [ ] 双击桌面快捷方式，应用能在 10 秒内启动
- [ ] 主窗口显示正常，无白屏或报错
- [ ] 左侧导航栏正常显示：面试台、简历库、会话记录、设置、模拟训练、作战室
- [ ] 顶部标题栏显示"获面通"和应用图标
- [ ] 最小化、最大化、关闭按钮可用

## 2. API 设置

- [ ] 进入设置页，8 个分区索引显示正常
- [ ] 在 DeepSeek/阿里/OpenAI 中粘贴 Key 并保存
- [ ] 点击"测试连接"返回成功和延迟毫秒数
- [ ] 关闭应用重启后，Key 仍然存在
- [ ] 金额预算可以设置和保存
- [ ] 检查安装目录，确认没有生成 `settings.json`、`sessions.json`、`usage.json`

## 3. 简历库

- [ ] 新增候选人，填写姓名和岗位
- [ ] 导入一份 PDF 简历（可以用测试文件）
- [ ] 导入一份 DOCX 简历
- [ ] 简历文件名、大小、格式显示正确
- [ ] 搜索候选人名称能筛选出对应简历
- [ ] 删除候选人有确认提示

## 4. 面试台

- [ ] 切换到有简历的候选人
- [ ] 手动输入问题并点击"生成回答"
- [ ] 先显示稳场话术，再显示完整回答
- [ ] 回答依据和风险检测正常显示
- [ ] 新会话可以保存并出现在会话记录里

## 5. 语音转写（如已配置 Deepgram）

- [ ] 麦克风按钮可以点击
- [ ] 语音设置面板显示设备列表和音量条
- [ ] Deepgram 测试连接通过
- [ ] 开启麦克风后能看到实时转写文本
- [ ] 停止转写后恢复可操作状态

## 6. 会话记录

- [ ] 刷新后能看到刚才保存的会话
- [ ] 打开历史会话能看到问答内容
- [ ] 重命名会话正常
- [ ] 导出 MD 文件能打开且内容完整
- [ ] 导出 Word 文件能打开且内容完整
- [ ] 删除会话有确认

## 7. 模拟训练

- [ ] 进入模拟训练页
- [ ] 选择训练类型（如数据分析）和题数
- [ ] 点击开始训练后生成第一题
- [ ] 输入回答并提交，有点评和分数
- [ ] 完成所有题目后生成最终复盘
- [ ] 导出 MD/Word 正常

## 8. 悬浮窗

- [ ] 点击顶部悬浮窗按钮能打开
- [ ] 悬浮窗显示当前问题和答案
- [ ] 最小化、关闭、最大化按钮可用
- [ ] 主窗口生成答案后悬浮窗同步更新

## 9. 作战室与体检

- [ ] 进入作战室
- [ ] 点击开始体检
- [ ] 各项检查显示通过/失败
- [ ] 失败项有原因说明和跳转入口

## 10. 帮助中心与文档资源

- [ ] 进入帮助中心
- [ ] 搜索 `语音不能用`，能看到语音排障文档
- [ ] 搜索 `打包`，能看到打包相关文档
- [ ] 点击打开文档，能成功打开 `.md` 文件
- [ ] 关闭软件后重新打开，帮助中心仍可搜索

## 11. 备份与隐私

- [ ] 进入设置 → 隐私安全，开关正常
- [ ] 导出备份能生成 JSON 文件
- [ ] 导入备份后数据刷新
- [ ] 隐私模式开关不影响功能

## 12. 退出与重开

- [ ] 正常关闭应用
- [ ] 重新打开应用
- [ ] 上次的设置和会话仍然存在
- [ ] 没有报错弹窗
