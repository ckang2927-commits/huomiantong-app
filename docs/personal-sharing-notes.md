# 个人使用与朋友分发边界说明

> 用途：明确获面通的使用范围、限制和不适用范围。

---

## 1. 使用范围

### 允许的用途
- ✅ **个人使用**：自己在面试准备或面试过程中使用。
- ✅ **给朋友用**：打包安装包直接给朋友安装使用。
- ✅ **演示和教学**：用于面试培训、模拟练习场景。
- ✅ **本地测试**：在自己的电脑上测试和体验功能。

### 不适用的用途
- ❌ **商业销售**：不能将获面通作为商业产品出售或租赁。
- ❌ **上架应用商店**：当前版本未针对商店审核准备。
- ❌ **企业级部署**：没有多用户管理、权限控制、审计日志等企业功能。
- ❌ **SaaS 服务**：不是云服务，不能多人同时在线使用。

## 2. 隐私与数据说明

- 所有数据存储在本地计算机的 `%APPDATA%/huomiantong/` 目录。
- API Key 使用操作系统提供的安全存储（safeStorage）加密。
- 不会自动上传任何用户数据。
- 语音转写数据通过 Deepgram 服务处理，仅在音频传输过程中经过网络。
- AI 回答通过用户配置的 API 服务商处理（DeepSeek/阿里/OpenAI/Anthropic）。

## 3. 安全提醒

- ⚠️ **API Key 保护**：不要将包含 API Key 的备份文件分享给他人。
- ⚠️ **屏幕分享注意**：远程面试或录屏时，注意悬浮窗可能暴露答案内容。
- ⚠️ **导出文件脱敏**：导出和分享会话文件前，建议启用隐私模式。
- ⚠️ **安装包来源**：只从可信渠道获取安装包，核对文件版本和大小。

## 4. 技术依赖

获面通依赖以下外部服务：

| 服务 | 用途 | 是否需要网络 | 免费额度 |
|------|------|-------------|----------|
| DeepSeek / 阿里 / OpenAI / Anthropic | AI 回答生成 | 是 | 各厂商注册赠金 |
| Deepgram | 语音转写 | 是 | $200 免费额度 |
| 操作系统 | 窗口管理、安全存储 | 否 | — |

没有 API Key 时部分功能受限（本地兜底训练、无法生成回答、无法语音转写）。

- AI 生成的内容仅供参考，不构成专业建议。
- 使用者应对面试过程中的行为和回答负责。
- 开发者不对因使用本软件产生的任何后果承担责任。
