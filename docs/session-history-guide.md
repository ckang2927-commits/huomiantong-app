# 获面通：会话记录使用指南

> 保存和回顾你的面试与训练记录。

## 基本操作

- **刷新** → 重新加载本地会话列表
- **打开** → 查看会话的详细问答时间线
- **重命名** → 修改会话标题
- **删除** → 单条删除或批量选中后删除
- **筛选** → 按候选人筛选，只显示对应会话

## 导出

- **Markdown 导出** → 生成 .md 文件，可用任何文本编辑器打开
- **Word 导出** → 生成 .docx 文件，格式更丰富
- **批量导出** → 选中多个会话后批量导出

## 复盘看板

会话记录顶部显示统计看板：
- 高频题型分布
- 回答质量趋势
- 风险点汇总


## 会话列表操作

### 刷新
- 点击"刷新"按钮重新加载本地会话列表
- 用于查看最新保存的会话，或手动同步多窗口操作

### 打开查看
- 点击会话条目进入详情页，查看完整的问答时间线
- 详情页展示：问题、AI 回答（含流式内容）、依据来源、口语评分、时间戳

### 重命名
- 右键点击会话或点击重命名按钮
- 输入新名称后自动保存
- 名称支持中英文、数字和常用符号，避免使用 `/` `:` `*` `?` 等文件名非法字符

### 删除
- **单条删除**：点击会话旁的删除按钮，确认后删除
- **批量删除**：勾选多个会话后点击"删除选中"，确认后批量删除
- 删除操作不可撤销，建议先导出备份

### 筛选
- 按下拉框中按候选人筛选，只显示对应候选人的会话
- 切换候选人后，会话列表自动更新
- 筛选不影响其他管理操作

## 导出说明

### Markdown 导出
- 生成 `.md` 文件，可用任何文本编辑器打开
- 保留完整的问答内容和时间线
- 适合存档和进一步编辑

### Word 导出
- 生成 `.docx` 文件，格式更适合打印和分享
- 需要系统安装 LibreOffice（可在设置中配置路径）
- 如果未配置 LibreOffice，导出按钮会提示安装或配置

### 隐私脱敏
- 如果开启了隐私模式，导出内容会自动脱敏
- 脱敏范围：候选人姓名、手机号、邮箱、公司名等个人身份信息
- 脱敏不影响原始会话内容，仅影响导出文件

## 会话与训练的关系

- 普通面试会话：面试台产生的问答记录，自动保存或手动保存
- 训练会话：模拟训练完成后，点击"保存到会话记录"后出现在会话列表中
- 训练会话包含：每题问答、口语评分、参考答案和最终复盘报告
- 训练会话可以像普通会话一样查看、导出和删除

## 常见问题

**Q：为什么看不到刚保存的会话？**
A：点击刷新按钮重新加载列表。如果仍然看不到，检查是否筛选了其他候选人。

**Q：会话可以跨电脑同步吗？**
A：当前版本为本地优先设计，会话仅保存在本机。可以通过"导出备份 → 导入备份"的方式迁移到其他电脑。

**Q：误删了会话能恢复吗？**
A：不能直接恢复。如果之前有导出备份，可以通过导入备份恢复。建议定期导出备份。

**Q：会话占多少磁盘空间？**
A：会话以 JSON 格式存储，每条会话通常 5-50KB。1000 条会话约占用 10-50MB 空间。
