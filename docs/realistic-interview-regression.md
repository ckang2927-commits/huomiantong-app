# 拟真面试本地回归说明

本回归用于验证拟真面试的基础逻辑，不调用真实 API，不启动麦克风，也不生成安装包。

## 运行命令

```bash
npm run validate:realistic
```

## 当前覆盖场景

- 配置边界值归一化：面试时长限制在 5-180 分钟，题数限制在 3-40 题，声音 URI 会去空格并限制长度。
- 非法配置回退：非法难度、非法面试官风格、非法追问策略、非法侧重点会回退默认配置。
- 数据分析师题库规模：确认内置题库为 500 题，并覆盖 easy、medium、hard、pressure 四种难度。
- 侧重点选题：压力表达场景优先命中沟通/压力类题目；项目深挖场景优先命中项目深挖类题目。
- 已使用题排除：上一题已经问过后，下一次选题不会重复同一道题。

## 当前结论

2026-08-03 本地回归通过 5/5。P3-10 可视为“本地回归通过”，但仍需要用户用真实麦克风、真实语音播报和完整拟真面试流程做人工验收。
