# 背景资料补全中心 — 设置中心帮助入口补充方案

> 说明背景资料补全中心的文档和 UI 如何在设置中心展示。

---

## 当前状态

背景资料补全中心目前以静态 UI 卡片形式展示在设置页的"诊断日志"分区中，包括：

1. **BackgroundPrepPreviewPanel** — 7 个资料包入口 + 来源标签 + 可信度等级
2. **BackgroundPrepResultPreview** — 示例结果预览表格 + 占位保存按钮
3. **BackgroundPrepConsistencyReport** — 一致性检查冲突卡片示例

## 入口位置

**设置页 → 诊断日志分区**（SettingsView diag section）

该分区现有组件：
- About & Diagnostics（关于与诊断）
- 帮助与文档（HelpQuickLinksPanel）
- **背景资料补全中心（新增）**
- **资料包结果预览（新增）**
- **一致性检查报告（新增）**
- FAQ（常见问题）

## 最终产品入口方案

### 方案一：独立设置分区（推荐）

在 SETTINGS_SECTIONS 中新增 `background` 分区：

```typescript
{ id: 'background', icon: FileText, label: '背景资料', desc: '补全中心与资料包' }
```

**优点**：独立入口，用户容易找到
**缺点**：设置分区数量增加，需要重新布局

### 方案二：保留在诊断日志分区

延续当前设计，将背景资料卡片放在诊断日志区。

**优点**：改动最小
**缺点**：功能归属不够直观

### 方案三：作为训练页的独立面板

在 TrainingView 或 WorkspaceView 中以独立面板形式展示。

**优点**：使用场景更匹配
**缺点**：需要在面试台或训练页面新增入口

## 文档入口

所有背景资料补全相关的文档已通过 `docs/README.md` 导航页汇集，用户可在设置页的"帮助与文档"卡片中找到 `docs/background-prep-center.md` 等文档路径。
