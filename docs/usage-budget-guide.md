# 获面通：用量预算与费用说明

> 最后更新：2026-07-22  
> 重要提醒：软件里的金额是**预算估算**，不是服务商实时账单。真实扣费、免费额度、汇率和优惠，以 DeepSeek、阿里百炼、OpenAI、Anthropic、Deepgram 各自官网和账单后台为准。

---

## 1. Token 和金额的关系

AI 模型通常按 **Token** 计费。可以粗略理解为：模型读进去多少内容、输出多少内容，就会消耗多少 Token。

每次回答的费用大致由两部分组成：

```text
估算费用 = 输入 Token × 输入估算单价 + 输出 Token × 输出估算单价
```

输入通常包括：

- 系统提示词
- 岗位 JD
- 正式简历、万字简历和其他简历材料
- 面试官问题
- 当前会话上下文

输出通常包括：

- 稳场话术
- AI 正式回答
- 训练点评或复盘报告

## 2. 为什么不直接写死价格

模型价格不是稳定常识，可能因为这些原因变化：

- 服务商调整模型价格
- 同一模型输入价和输出价不同
- 汇率变化
- 账户优惠、赠送额度、缓存折扣不同
- 不同地区和不同计费版本政策不同
- Deepgram 语音价格和免费额度可能跟账户政策有关

所以获面通只做一个“心里有数”的预算估算，不能替代官网账单。

## 3. 设置页怎么看预算

在 `设置中心 → API 模型` 里，每个模型服务商卡片会显示：

- **当前模型 Token**：当前选中模型累计消耗量
- **当前模型估算花费**：按软件内估算价计算
- **总估算花费**：该服务商下所有模型合计估算
- **剩余预算**：你设置的金额预算减去估算花费

如果你设置了金额预算，达到预算后软件会停用对应模型，避免继续扩大支出。

## 4. 建议怎么设置预算

个人使用建议：

| 使用强度 | 建议预算 | 适合情况 |
|---|---:|---|
| 轻度体验 | 5-10 元 | 偶尔问答、测试功能 |
| 日常练习 | 20-50 元 | 每周多次模拟训练 |
| 高频备面 | 50-100 元 | 连续准备多场面试 |

这只是控制风险的上限，不代表一定会花完。

## 5. 省钱建议

1. 日常训练优先用 fast/flash 类模型。
2. 重要面试、复杂追问再切换到 pro/max/高级模型。
3. 回答长度控制在合适范围，不要默认生成超长答案。
4. 简历材料要完整，但不要把无关材料全部塞进去。
5. 预热缓存会提前消耗 Token，但命中后能提升临场速度。
6. 语音转写按时长消耗，长时间空开麦克风也可能产生费用。

## 6. Deepgram 语音费用怎么看

Deepgram 通常按音频时长计费。你应该重点看：

- Deepgram 后台余额
- 免费额度是否还有
- 免费额度是否有有效期
- 当前项目使用的转写模型和语言
- 是否绑定账单方式

如果软件里出现 402，通常表示余额不足、免费额度过期、账单未开通或账户计费状态异常。

## 7. 后续维护规则

每次要更新估算价时，需要同时检查：

- `src/renderer/components/usage/usagePricing.ts`
- `src/renderer/components/settings/BudgetExplainerPanel.tsx`
- `src/renderer/components/settings/ModelProviderPanel.tsx`
- `docs/usage-budget-guide.md`
- `docs/usage-budget-examples.md`

更新时必须写清楚“估算价更新时间”，不要把估算价写成官方实时价格。
