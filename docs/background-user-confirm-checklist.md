# 背景资料保存前用户确认清单

> 保存背景资料到"其他简历"前，用户需要逐条确认以下内容。
> 系统自动标记待确认项，用户逐条勾选后才可以保存。

---

## 保存前置条件

- [ ] 我已逐条核对资料内容
- [ ] AI 模拟内容已标注，不会当作事实使用
- [ ] 薪资信息是准确的（或已标注为估算）
- [ ] 公司信息来自可信来源
- [ ] 隐私字段已选择跳过或泛化
- [ ] 所有冲突字段已统一口径

## 逐条确认项

### 来源和可信度

- [ ] 我知道哪些字段来自 AI 模拟（标注为"低可信度"）
- [ ] 我知道哪些字段标注为"待确认"
- [ ] 公开资料字段我已经在某处看到过（官网/招聘页/新闻）

### 薪资信息

- [ ] 期望薪资是我能接受的
- [ ] 最低接受薪资是我真实的底线
- [ ] 上家薪资是准确的（或已泛化处理）
- [ ] 薪资谈判策略仅是参考思路

### 公司信息

- [ ] 我知道公司信息可能不完整或滞后
- [ ] 面试时我不会说有疑问的细节
- [ ] 竞品信息来自公开渠道

### 个人隐私

- [ ] 我没有填写不愿分享的隐私信息
- [ ] 地址、家庭信息已泛化处理
- [ ] 如果面试中被追问隐私，我知道可以跳过

### 一致性

- [ ] 同一字段在不同资料包中说法一致
- [ ] 离职原因统一口径
- [ ] 工作年限统一口径
- [ ] 薪资信息统一口径

## 保存后确认

- [ ] 保存后资料可以在"其他简历"中找到
- [ ] 我知道保存后可以编辑和删除
- [ ] 我知道保存后不会自动更新
