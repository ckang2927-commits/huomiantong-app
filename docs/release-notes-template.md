## 填写说明

1. 每次发布新版本前，复制上方模板，填写本次内容。
2. "更新方式"根据实际情况选择：**覆盖安装**（数据保留）或 **全新安装**（首次使用）。
3. 如果本次没有某项（如新增/修复），可以整行删除，但保留结构。
4. 已知问题需要更新 `docs/known-issues.md` 并在此引用。

---

### 填写示例

```markdown
## 版本 v0.2.0 — 2026-07-23

### ✨ 新增
- 拟真面试模式：支持 AI 面试官提问、语音作答和报告生成
- 背景资料补全中心：7 个资料包入口和结果预览
- 快捷键体系：全局快捷键和设置页快捷键说明

### 🛠 修复
- 流式输出偶现断句异常
- 隐私模式会话导出未脱敏
- 创建候选人时岗位名称过长导致 UI 偏移

### ⚠️ 已知问题
- 快捷键暂不支持自定义绑定（计划 v0.3.0）
- 电脑音频在部分 Win10 版本不可用（依赖 Electron 升级）
- 打包版首次启动时 SmartScreen 可能拦截（见 docs/windows-install-guide.md）

### 📦 更新方式
覆盖安装（保留本地数据和配置）

### 📝 备注
本次重点优化了面试台的流式输出体验和拟真面试流程。
```
