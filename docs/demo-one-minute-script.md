# 一分钟演示脚本

> 用途：给朋友快速展示获面通的核心能力，控制在 1 分钟内讲完。
> 话术风格：自然口语化，像当面介绍。

---

## 开场（10 秒）

"给你看个好东西——获面通，一个本地运行的 AI 面试辅助工具。"

## 核心演示（30 秒）

"平时面试最怕什么？反应不过来，或者答得不够好。
获面通就是帮你解决这个的。
它能实时听面试官的问题——或者你手动输入也行——然后立刻结合你的简历生成回答。
看，这是简历，这是问题，这边就是 AI 给你的回答，还有依据来源。"

## 亮点收尾（15 秒）

"所有数据都存在本地，不会上传。而且支持 DeepSeek、阿里、OpenAI 多个模型。
我打包了一个安装包，你要不要拿去试试？"

## 话术要点

- **不要说**："这是一个 Electron + React + TypeScript 项目"
- **要说**："面试的时候它能帮你想答案"
- **不要说**："需要配置 Deepgram API Key"
- **要说**："有语音的话它能实时听问题，没有语音打字也行"

## 如果被问"这是什么原理"

"就是在本地跑 AI 模型，你的简历和问题发给 AI，它基于你的经历帮你组织回答。所有数据都只在你的电脑上，不会上传到别的地方。"

## 如果被问"安全吗"

"代码是开源的，你可以自己看。API Key 用系统加密存储，所有数据在本地，不联网的时候也能用部分功能。"
