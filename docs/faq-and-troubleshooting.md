## 常见问题

### 1. 为什么测试连接失败？

- **Key 填错**：重新复制 Key，确认没有多余空格或换行
- **Key 填错位置**：DeepSeek 的 Key 不要填到 OpenAl 的字段里
- **网络不通**：检查能否访问对应服务商；OpenAI/Anthropic 需要代理
- **Key 过期**：登录服务商后台确认 Key 是否有效
- **Base URL 不对**：检查地址末尾是否包含 `/v1` 等路径

### 2. 麦克风转写没有反应？

1. 先在设置页测试 Deepgram 连接是否通过
2. 检查 Windows 麦克风权限是否开启
3. 在语音设置中选择正确的麦克风设备
4. 使用"本地麦克风诊断"排查硬件
5. 检查 Deepgram 免费额度是否用完（返回 402）

### 3. AI 回答太慢怎么办？

- 切换为 **DeepSeek v4 Flash** 或 **qwen3.6-flash** 等快速模型
- 检查网络延迟（设置页测试连接会显示延迟）
- 简历内容过长会增加输入时间
- 开启"预热缓存"提前生成常见问题的缓存答案

### 4. 保存会话失败？

- 检查磁盘空间是否充足
- 重启应用后重试
- 如果持续失败，导出备份后重新安装

### 5. 导出的 Word/MD 文件是空的？

- 确保会话中有问答内容
- 尝试重新保存会话后再导出
- 如果使用隐私模式，确认内容已脱敏

### 6. 模拟训练没有出题？

- 检查 API Key 是否配置且测试通过
- 没有 API Key 时系统会进入**本地兜底训练**
- 检查训练模板是否选择了正确的题型
- 固定题纲的题目会优先使用

### 7. 回答太长/太短？

- 在设置中切换回答风格：`fast`（简短）/ `standard`（标准）/ `star`（详细）
- 回答长度也受模型影响

### 8. 切换候选人后回答还在用旧简历？

- 保存当前会话后开启新会话
- 新问题会自动使用新候选人的简历

### 9. 隐私模式和普通模式有什么区别？

| 对比项 | 普通模式 | 隐私模式 |
|--------|---------|---------|
| 面试台显示 | 完整信息 | 完整信息 |
| 悬浮窗显示 | 完整信息 | 脱敏显示 |
| 导出 MD/Word | 完整信息 | 姓名/公司名被替换 |
| 回答质量 | 正常 | 不受影响 |

### 10. 数据存在哪里？安全吗？

- 所有数据存储在本地电脑：`%APPDATA%/huomiantong/`
- API Key 使用操作系统安全存储加密
- 不会自动上传到任何服务器
- 诊断日志只在本地记录

## 错误索引速查

| 看到什么 | 可能原因 | 先去哪里看 |
|---------|---------|-----------|
| 401 Unauthorized | API Key 无效 | 检查 Key 是否正确 |
| 402 Payment Required | 余额不足/免费额度用完 | 去服务商后台充值 |
| 403 Forbidden | Key 无权访问该模型 | 检查模型权限/白名单 |
| 404 Not Found | Base URL 或模型名错误 | 检查 URL 和模型名 |
| 429 Too Many Requests | 请求太频繁 | 等待后重试 |
| "权限被拒绝" | 系统麦克风权限未开启 | Windows 隐私设置 |
| "设备未找到" | 麦克风未连接或驱动异常 | 检查硬件和驱动 |
| "Not supported" | 电脑音频不支持 | 更新系统或改用麦克风 |
| "保存失败" | 磁盘空间或文件写入问题 | 检查磁盘、重启应用 |
| "导入失败" | 备份文件格式不兼容 | 确认是同一版本导出 |

## 更多常见问题

### 11. 模型返回的内容不相关或质量差？

- **模型选错**：检查当前使用的模型是否适合面试场景。DeepSeek Chat 比 DeepSeek Reasoner 更适合实时回答，GPT-4o 比 GPT-3.5-turbo 质量更高但更慢。
- **JD 或简历不完整**：AI 回答依赖简历和 JD 内容。如果两者都为空，只能给通用建议。建议先导入简历并填写 JD。
- **提示词被裁剪**：长时间面试中，超出上下文窗口的早期内容会被丢弃。这是正常行为，可以在设置中调整上下文长度。
- **服务商负载高**：高峰时段模型响应可能变慢或质量下降，可以暂时切换到其他服务商。

### 12. 保存训练/会话失败？

- **磁盘空间不足**：检查 `%APPDATA%/huomiantong/` 所在分区是否有足够空间。
- **文件名包含非法字符**：会话标题如果包含 `/` `:` `*` `?` `"` `<` `>` `|` 等字符可能导致保存失败。建议使用中英文、数字和短横线命名。
- **JSON 解析错误**：极少数情况下会话数据损坏会导致无法保存。可以尝试导出备份后重置应用数据。
- **权限问题**：以管理员身份运行一次获面通，确保数据目录权限正确。

### 13. 导出 Word 或 MD 失败？

- **Word 导出依赖 LibreOffice**：如果系统中没有安装 LibreOffice 或路径配置不对，Word 导出会失败。可以在设置中检查 LibreOffice 路径，或者在未配置时改用 MD 导出。
- **MD 导出后中文乱码**：确认导出时选择的编码为 UTF-8。使用系统自带记事本打开时选择"另存为 → 编码 UTF-8"。
- **会话内容为空**：未完成的训练或没有问答内容的会话无法导出有效文件。先完成训练或确认会话有内容再导出。
- **隐私模式导致内容为空**：如果开启了隐私模式，导出时部分内容会被脱敏处理，但不应该完全为空。如果导出文件为空，检查隐私模式设置。

### 14. API 测试连接成功但生成回答时出错？

- **模型名不一致**：测试连接和生成回答可能使用不同的模型名。检查设置中"回答模型"和"测试连接"的配置是否一致。
- **Token 限额已用完**：某些服务商有 API 调用频率限制（RPM）或 Token 限额（TPM）。超额后请求会被拒绝，等待一段时间再试。
- **多服务商路由问题**：如果配置了多个服务商，路由规则可能导致请求发到了未配置 Key 的服务商。检查路由配置。

### 15. 软件启动后白屏或闪退？

- **显卡驱动过旧**：Electron 应用需要较新的显卡驱动。更新显卡驱动到最新版本。
- **系统缺少 VC++ 运行库**：安装 `Visual C++ Redistributable for Visual Studio 2015-2022`。
- **数据目录损坏**：重命名 `%APPDATA%/huomiantong/` 目录后重启应用（会丢失本地数据，建议先导出备份）。
- **内存不足**：关闭其他大型应用后重试。获面通至少需要 2GB 可用内存。

### 16. Deepgram 转写延迟很高？

- **网络延迟**：Deepgram 是云端服务，网络质量直接影响转写延迟。检查网络连接，或切换到延迟更低的服务商。
- **音频质量差**：麦克风噪音大或说话声音小会导致 Deepgram 需要更多时间处理。检查麦克风设置和距离。
- **免费额度限制**：Deepgram 免费额度用完后，转写可能会变慢或被限制。在 Deepgram 后台检查账户状态。

### 17. 悬浮窗不显示或显示异常？

- **快捷键冲突**：其他软件占用了相同的快捷键。在设置中查看全局快捷键，关闭冲突软件。
- **多显示器问题**：在扩展屏幕模式下，悬浮窗可能出现在主屏之外。尝试在主屏上重新打开，或在设置中重置悬浮窗位置。
- **窗口超出屏幕**：如果悬浮窗上次关闭时位置超出当前屏幕边界，再次打开可能看不到。重置窗口位置。

### 18. 如何彻底卸载获面通？

1. 先导出备份（设置 → 备份 → 导出），保留会话和配置。
2. 关闭获面通。
3. 在 Windows 设置 → 应用 → 已安装的应用中找到"获面通"并卸载。
4. 手动删除 `%APPDATA%/huomiantong/` 目录（可选，删除后本地数据不可恢复）。
5. 卸载后如有残留进程，重启电脑即可。
