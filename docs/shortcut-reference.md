# 获面通快捷键参考

> 适用版本：v0.1.0  
> 快捷键均为全局生效，即使应用在后台（悬浮窗状态下）也可使用。

---

## 操作快捷键

| 快捷键 | 动作 | 功能说明 |
|--------|------|---------|
| `Ctrl + Enter` | 生成回答 | 在面试台输入问题后提交，触发 AI 生成回答 |
| `Ctrl + L` | 开始/停止录音 | 开启或停止麦克风实时语音转写 |
| `Ctrl + M` | 麦克风静音 | 切换麦克风静音，避免自己的讲话继续进入转写 |
| `Ctrl + H` | 显示/隐藏悬浮窗 | 打开或关闭独立悬浮窗，显示当前问答 |
| `Esc` | 关闭悬浮窗 | 关闭当前打开的悬浮窗 |
| `Ctrl + S` | 保存当前会话 | 保存当前面试会话到本地记录 |

## 页面导航

| 快捷键 | 动作 | 功能说明 |
|--------|------|---------|
| `Ctrl + 1` | 导航到面试台 | 切换到面试台页面 |
| `Ctrl + 2` | 导航到模拟训练 | 切换到模拟训练页面 |
| `Ctrl + 3` | 导航到作战室 | 切换到作战室（面试前体检） |
| `Ctrl + 4` | 导航到简历库 | 切换到简历库页面 |
| `Ctrl + 5` | 导航到设置 | 切换到设置页面 |
| `Ctrl + 6` | 导航到会话记录 | 切换到会话记录页面 |

## 使用说明

- **输入框中**：除 `Ctrl + Enter` 外，其他快捷键不会在输入框/文本编辑区域触发，避免干扰打字。
- **重复绑定**：如果多个应用注册了相同的全局快捷键，以最后启动的应用为准。如有冲突，可以关闭其他应用的快捷键。
- **自定义**：当前版本快捷键为固定配置，暂不支持在界面中直接修改。后续版本会支持自定义快捷键绑定。
- **恢复默认**：如需恢复默认快捷键，可通过设置页面的备份功能重置。

## 冲突提醒

如果以下快捷键与你电脑上的其他软件冲突：

| 快捷键 | 常见冲突软件 |
|--------|-------------|
| `Ctrl + S` | 浏览器保存页面 |
| `Ctrl + Enter` | 微信/QQ 发送消息 |
| `Ctrl + 1~6` | 浏览器标签切换 |

建议在面试前关闭可能冲突的软件，或调整对应软件的快捷键设置。
