# 获面通：产品说明与隐私摘要

> 一句话：一个本地优先的 Windows 面试辅助工具。

---

## 产品定位

获面通帮你：
- 实时转写面试官提问（麦克风或电脑音频）
- 基于简历和 JD 生成 AI 回答参考
- 通过模拟训练提升面试表现
- 保存和回顾面试记录

**它不是**：
- ❌ 替你在面试中"代答" — AI 回答仅供参考，最终由你决定说什么
- ❌ 云端/SaaS 服务 — 所有数据存储在你的本地电脑
- ❌ 面试题库平台 — 不提供海量题库，重点是对你的简历和 JD 做定制化支持
- ❌ 录音软件 — 不录制面试音频，仅实时转写

## 适用场景

| 场景 | 说明 |
|------|------|
| **线上面试准备** | 开着获面通，实时转写面试官提问，AI 辅助生成回答思路 |
| **模拟练习** | 使用模拟训练功能，针对简历和 JD 进行专项训练 |
| **面试复盘** | 回放已保存的面试会话，分析回答质量和改进空间 |
| **朋友内测** | 打包后给朋友试用，帮助提升面试表现 |

## 数据说明

### 存储位置
- **本地目录**：`%APPDATA%/huomiantong/`
- **存储内容**：应用设置、API Key（加密存储）、会话记录、训练记录、用量统计、备份文件
- **不存储**：原始音频、面试录音、屏幕录制

### 数据安全
- API Key 在本地加密存储，不会明文保存在配置文件中
- 所有数据不经过获面通服务器（没有云端服务）
- AI 回答直接通过 API 请求服务商，不经过第三方代理（除非自定义 Base URL）

### 隐私说明
- 获面通**不收集**使用数据、统计信息或个人隐私
- 语音转写数据直接发送到 Deepgram（你配置的服务商），不经获面通中转
- AI 回答请求直接发送到 AI 服务商（如 DeepSeek/阿里/OpenAI），不经获面通中转
- 你的简历内容和会话记录仅保存在本机

## 使用边界

### 适合个人/朋友使用
- 个人面试准备和模拟训练
- 小范围朋友之间分享使用
- 不涉及商业收费、SaaS 服务或公开分发

### 不适合商业场景
- 不支持多用户登录和权限管理
- 不支持云端同步和团队协作
- 不提供商业 SLA 或技术支持

## 技术和系统要求

- **操作系统**：Windows 10/11（64 位）
- **内存**：建议 4GB 以上
- **磁盘**：安装约 200MB，数据存储按使用量增长
- **麦克风**：需要支持 VoIP 质量的麦克风（推荐 USB 或内置麦克风）
- **网络**：需要互联网连接（用于 AI 服务和语音转写）
- **附加软件**：Word 导出需要 LibreOffice（可选）

- 当前版本：0.1.0

- 数据兼容性：同一大版本内数据格式向前兼容
