# 五分钟完整演示流程

> 用途：给朋友或同事完整演示获面通的全部核心功能。
> 准备：已安装应用、已配置 API Key（DeepSeek + Deepgram）、已导入示例候选人简历。

---

## 第一阶段：基本配置（1 分钟）

### 话术
"打开应用后，第一步是配置 API。获面通需要两个服务：一个用来生成回答，一个用来语音转写。"

### 操作步骤
1. 启动获面通，进入**设置**页。
2. 在 DeepSeek 卡片中粘贴 API Key，点击**测试连接**，演示成功状态。
3. 在 Deepgram 卡片中粘贴 Key，同样测试连接。
4. 切回**面试台**。

## 第二阶段：简历导入（30 秒）

### 话术
"然后导入你的简历，这样 AI 就能基于你的经历来回答问题。"

### 操作步骤
1. 进入**简历库**。
2. 新增候选人，填写姓名和岗位。
3. 导入一份 PDF/ DOCX 简历，展示文件名和大小。
4. 切回**面试台**，确认简历已加载。

## 第三阶段：手动提问演示（1 分钟）

### 话术
"现在模拟面试。我先手动输一个问题试一下。"

### 操作步骤
1. 在面试台问题输入框输入："请做一个自我介绍。"
2. 点击**生成回答**。
3. 展示：先出现稳场话术 → 流式输出完整回答 → 回答依据 → 质量评分。
4. 指出回答中的简历依据来源。

## 第四阶段：语音转写演示（1 分钟）

### 话术
"更酷的是它能实时听面试官的问题。我开启麦克风试一下。"

### 操作步骤
1. 点击**麦克风转写**按钮。
2. 对着麦克风说一句模拟面试问题，例如："你最大的优势是什么？"
3. 展示实时转写文本出现在转录面板中。
4. 点击**生成回答**，展示基于语音问题的回答生成。

## 第五阶段：会话保存与导出（30 秒）

### 话术
"面完之后，所有问答都可以保存下来，还能导出。"

### 操作步骤
1. 点击**保存会话**，输入会话名称。
2. 进入**会话记录**，找到刚才保存的会话。
3. 点击导出 → **导出 Markdown**，打开导出的文件展示内容。

## 第六阶段：模拟训练（1 分钟）

### 话术
"它还有模拟训练功能，可以针对特定岗位练习面试。"

### 操作步骤
1. 进入**模拟训练**页。
2. 选择"数据分析"模板，10 道题。
3. 点击**开始训练**，展示第一题生成。
4. 输入一个简短回答并提交，展示评分和点评。
5. 展示训练记录面板中的答题记录。

## 收尾（30 秒）

"以上就是获面通的核心功能。所有数据都存在本地，API Key 加密保存，不会泄露。
如果要打包成安装包，我可以给你打一个，直接装就能用。"

---

## 演示检查清单

- [ ] API Key（DeepSeek + Deepgram）已配置并测试通过
- [ ] 至少有一个候选人简历已导入
- [ ] 麦克风可用
- [ ] 应用已启动，页面无报错
- [ ] 演示前已清空敏感信息（如不需要展示的 Key）
