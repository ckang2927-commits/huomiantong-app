# 获面通 UI 总布局蓝图

这份文档先把“文字界面”定下来：每个页面放什么、占多大、谁在左谁在右、哪些模块必须常驻。
后续所有 UI 调整，先对照这份蓝图，再进代码。

## 1. 全局原则

- 侧边栏只保留**左侧图标栏**，不再显示文字，避免占空间。
- 所有页面统一使用“**顶部标题区 + 主内容区**”结构。
- 主内容区优先给“工作区”让位，尽量减少无意义边框和重复标题。
- 重要状态只保留 3 类：运行状态、服务状态、风险状态。
- 所有保存、导出、启动、停止按钮必须有明确反馈。
- 不做隐藏/规避检测功能，界面定位为可见的面试练习与辅助工具。

## 2. 全局壳

### 2.1 左侧图标栏

- 固定宽度：**86px 左右**（包含内边距，视觉上只保留图标）
- 内容：
  - 顶部 App Logo
  - 中部 8 个模块图标
  - 底部本地状态图标
- 图标顺序：
  1. 面试台
  2. 模拟训练
  3. 拟真面试
  4. 面试前作战室
  5. 简历库
  6. 会话记录
  7. 帮助中心
  8. 设置中心
- 只显示图标；鼠标悬停显示文字提示。
- 当前激活项用左侧细金色竖条标识。

### 2.2 顶部标题区

- 高度：**72px 左右**
- 位置：主内容区顶部，左右留白 24px。
- 左侧：当前页面标题 + 一句副标题。
- 右侧：状态胶囊 + 当前页面常用动作按钮。
- 胶囊只保留简短信息：
  - 麦克风已连接
  - DeepSeek 在线
  - 当前候选人
  - 当前模式

### 2.3 主内容区

- 主内容区统一采用卡片化布局。
- 卡片圆角：16~24px。
- 页面内滚动只允许发生在对应模块内部，不让整页乱滚。
- 主内容区默认左右留白：**24px**
- 页面内卡片间距：**16~18px**

## 3. 页面级布局

### 3.1 面试台 / 工作区

这是最重要的页面，优先占最多空间。

#### 页面结构

- 顶部：候选人概览条，**88~96px**
- 中部：三栏工作区
- 底部：可选浮动提示/快捷按钮区

#### 三栏比例

- 左栏：**30%**
- 中栏：**48%~50%**
- 右栏：**20%~22%**

#### 左栏：实时转写区

- 用途：
  - 麦克风/电脑音频转写
  - 手动补充问题
  - 暂停/继续接收
  - 自动回答开关
- 区块组成：
  - 顶部音频状态：**56~72px**
  - 转写列表：**260~320px**
  - 手动输入/生成按钮：**96~120px**
- 目标：让用户看见“当前问了什么”，不是只看技术状态。

#### 中栏：AI 答案区

- 用途：
  - 展示当前问题
  - 展示流式答案
  - 控制答案风格
  - 展示稳场短语/缩短/改写按钮
- 区块组成：
  - 问题条：**72~90px**
  - 主答案卡：占中栏主体，至少 **360px** 高
  - 底部动作条：**56~64px**
- 目标：这是视觉主角，宽度最大、信息最聚焦。

#### 右栏：依据与风险区

- 用途：
  - 简历命中
  - JD 匹配
  - 风险提醒
  - 估算用量
  - 当前上下文轮次
- 区块组成：
  - 总览分数卡：**72~88px**
  - 依据卡片列表：每条 **56~68px**
  - 风险提醒：单独高亮
- 目标：让用户知道“为什么这么答”，但不抢主答案的戏。

#### 工作区附加模块

- 面试前预热：放在工作区顶部的小卡片，**56~72px**
- 保存会话：放在顶部动作区
- 打开悬浮窗：放在顶部动作区

### 3.2 模拟训练

#### 页面结构

- 左侧：训练配置
- 右侧：模拟过程预览 / 训练报告

#### 比例

- 左栏：**58%**
- 右栏：**42%**

#### 左栏内容

- 模拟面试配置：题数、时长、难度、侧重点、面试官风格
- 默认题库入口
- 开始训练按钮
- 训练模式切换

#### 右栏内容

- 流程预览
- 当前题目卡
- 用户回答卡
- 每题反馈卡
- 最终报告入口

#### 训练页面目标

- 先看清配置，再进入面试。
- 重点展示“真人面试感”，不是刷题面板。

### 3.3 面试前作战室

#### 页面结构

- 顶部：总状态摘要，**80~96px**
- 中部：检查项网格
- 右侧/下方：诊断日志与处理建议

#### 比例

- 主检查区：**65%**
- 诊断区：**35%**

#### 检查项

- 简历完整度
- 候选人是否已选
- JD 是否已配置
- API 是否可用
- 麦克风是否正常
- 电脑音频是否可用
- 悬浮窗是否可用
- 预热缓存是否存在

#### 目标

- 开场前 3 分钟，告诉用户“能不能上场、哪里有风险、先补什么”。

### 3.4 简历库

#### 页面结构

- 顶部：搜索 + 导入 + 新增 + 保存
- 中部：左侧候选人列表 / 右侧文件列表

#### 比例

- 左栏：**28%~32%**
- 右栏：**68%~72%**

#### 左栏内容

- 候选人搜索
- 候选人卡片列表
- 新增/删除/重命名入口

#### 右栏内容

- 正式简历
- 万字简历
- 其他简历
- 每个文件显示：
  - 文件名
  - 格式
  - 添加时间
  - 文件大小
  - 悬停说明

#### 目标

- 让“找人”和“找文件”都很快。
- 其他简历不要做得太散，文件化、列表化、可搜索。

### 3.5 设置中心

#### 页面结构

- 顶部：设置总标题
- 下面：二级设置分区按钮
- 下方：当前分区内容

#### 分区建议

1. API 与模型
2. 面试与回答
3. 语音与音频
4. 悬浮窗设置
5. 快捷键设置
6. 数据与隐私
7. 模拟训练设置
8. 关于与诊断

#### 比例

- 顶部分区条：**56~64px**
- 内容区：单列或双列自适应

#### 目标

- 设置页不是大杂烩。
- 所有“配置类功能”都从这里找得到。

### 3.6 会话记录

#### 页面结构

- 顶部：刷新 / 导出 / 删除 / 多选
- 左侧：会话列表
- 右侧：会话详情

#### 比例

- 左栏：**30%**
- 右栏：**70%**

#### 左栏内容

- 搜索
- 多选
- 重命名
- 删除
- 下载

#### 右栏内容

- 问答时间线
- AI 标题
- 具体时间
- 关键依据
- 导出按钮

#### 目标

- 会话不是列表堆积，而是可复盘记录。

### 3.7 帮助中心

#### 页面结构

- 顶部：说明区 + 文档数量/本地优先状态
- 左侧：搜索框 + 分类筛选 + 高频问题
- 中间：匹配到的文档结果
- 右侧：使用建议 + 后续升级说明 + 高频文档

#### 比例

- 左栏：**28%~32%**
- 中栏：**42%~48%**
- 右栏：**20%~24%**

#### 搜索策略

- 第一版先搜索核心文档索引，不默认联网。
- 命中维度：标题、分类、关键词、常见问法、摘要、路径。
- 搜不到时给用户相似搜索建议，不直接编造答案。
- 打开文档时调用软件已有 `docs:open` 能力，只能打开 `docs/` 目录下的 `.md` 文件。

#### 后续升级

- 支持全量 `docs/` 自动索引。
- 支持正文片段预览。
- 支持 AI 基于本地文档生成解释。
- 支持用户确认后联网搜索公开资料。

#### 目标

- 用户有问题时先在软件内查，不用翻文件夹。
- 把我们每天沉淀的文档真正变成可用知识库。

## 4. 通用模块尺寸

### 4.1 卡片

- 常规卡片高度：**120~180px**
- 重点卡片高度：**240~360px**
- 列表项高度：**56~72px**
- 标签胶囊高度：**34~36px**

### 4.2 按钮

- 主按钮：高度 **40px~44px**
- 次按钮：高度 **36px~40px**
- 图标按钮：**44px × 44px**

### 4.3 弹窗 / 提示

- 保存成功提示：顶部中间，宽度 **320~420px**
- 错误提示：顶部中间，宽度 **360~460px**
- 确认弹窗：居中，宽度 **420~520px**

### 4.4 悬浮窗

- 默认：**560 × 360**
- 最小：**420 × 280**
- 最大：允许用户拖到接近屏幕宽度 60% 左右
- 上部内容区要可拉伸，不要固定死

## 5. 响应式规则

- 宽屏（≥1440）：三栏工作区完整展开。
- 中屏（1200~1439）：三栏仍保留，但右栏压窄。
- 窄屏（<1200）：工作区优先保证中栏宽度，右栏可折叠。
- 更窄时：转为上下堆叠，但答案区始终排第一。

## 6. 视觉优先级

1. 工作区答案
2. 转写与问题识别
3. 依据与风险
4. 候选人/简历选择
5. 设置与辅助入口

## 7. 实现顺序

1. 先固定左侧纯图标栏。
2. 再把工作区三栏定宽。
3. 然后重排训练、作战室、简历库、会话记录。
4. 最后统一设置中心和弹窗风格。

### 8.2 推荐执行顺序

1. **悬浮窗**：临场价值最高，先做极简可读版。
2. **面试台顶部信息区**：补齐面试台最后一块明显不统一的区域。
3. **模拟训练页**：功能重、页面长，适合做第二个大页面工程。
