# 获面通：语音排障决策树

> 语音问题出现时，按这个流程排查。

## 麦克风转写流程

```
点击麦克风按钮 →
├── 没反应？→ 检查 Deepgram 是否配置并测试通过
├── 显示"权限被拒绝"？→ Windows 设置开权限
├── 显示"监听中"但没文字？
│   ├── 音量条不动？→ 检查麦克风是否被静音/选对设备
│   └── 音量条动但无转写？→ Deepgram 连接异常，重新开始
└── 频繁断开？→ 网络不稳定，切换网络
```

## 电脑音频流程

```
点击电脑音频按钮 →
├── 提示"不支持"？→ 更新 Win10 到 1903+
├── 提示"选择来源"？→ 点刷新，选整个屏幕
├── 选了来源但没声音？
│   ├── 确认来源窗口正在播放音频
│   └── 重选后重新开始
└── 转写卡顿？→ 降低音频质量或改用麦克风
```
