# 获面通 v0.1.3 更新说明

发布日期：2026 年 7 月 31 日

这次更新重点修复安装后无法启动、更新重复下载和更新说明不清楚的问题。

## 修复问题

### 1. 修复安装后启动时报 JavaScript 错误

部分用户安装后启动会看到：

`Could not dynamically require ../bin/napi-v6/win32/x64/onnxruntime_binding.node`

原因是离线语音依赖的 Windows 原生模块被错误地打进了主进程代码。v0.1.3 已调整打包方式，让原生模块从安装包资源中正常加载。

### 2. 修复更新下载重复开始

更新下载过程中如果网络或安装器状态异常，可能出现第一次下载后报错，第二次到 100% 又重新下载，第三次才成功的情况。v0.1.3 优化了下载状态、错误处理和下载完成后的提示，减少重复下载。

### 3. 检查更新不再自动下载

现在点击“检查更新”只会检查版本：

1. 软件发现新版本。
2. 弹窗询问是否下载。
3. 用户点击“下载更新”后才开始下载。
4. 下载完成后，再由用户选择“重启安装”或“稍后安装”。

用户可以完全决定是否更新，不会因为误触检查按钮而直接开始下载。

## 新增体验

### 升级后首次启动显示更新说明

升级到 v0.1.3 后，软件会弹出本次更新说明，介绍修复内容和使用变化。关闭后不会反复打扰。

完整更新日志也可以在：

`设置 → 关于与诊断 → 更新说明`

中查看。

## 保留内容

升级不会删除以下本地数据：

- API Key 和模型设置
- 候选人简历
- 历史会话
- 模拟训练记录
- 面试复盘记录
- 三套本地面试官声音
- 500 道数据分析师题库

## 已知情况

- 当前 Windows 安装包仍未购买代码签名证书，首次安装可能显示“未知发布者”。
- 离线语音模型会增加安装包体积。
- 语音转写功能仍需要配置对应的语音服务 Key。

## 升级方式

旧版本用户可以在“设置 → 关于与诊断”中点击“检查更新”。发现 v0.1.3 后，先选择“下载更新”，下载完成后再选择“重启安装”。

也可以直接下载新的安装包覆盖安装。覆盖安装不会删除 `%APPDATA%/huomiantong/` 中的用户数据。
