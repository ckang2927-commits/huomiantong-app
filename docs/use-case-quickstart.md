# 获面通：场景化上手指南

> 按使用场景快速上手。

## 场景一：自己面试练习

1. 配置 DeepSeek API Key
2. 导入候选人简历
3. 进入面试台，输入问题或开麦克风
4. AI 实时生成回答建议
5. 保存会话，导出复盘

## 场景二：给朋友打包使用

1. 确认 API Key 已预填
2. 导出完整备份（含 Key）
3. 运行 npm run build 打包
4. 给朋友安装包 + 备份文件
5. 朋友导入备份即可使用

## 场景三：演示/展示

1. 使用示例候选人和 JD
2. 预热缓存展示快速回答
3. 模拟训练展示评分功能
4. 作战室展示一键体检
5. 悬浮窗展示同步效果
