# DeepSeek 任务书总入口

> 作用：把适合 DeepSeek 做的低风险工作统一收口，后续你只要把这份文档丢给它，再配合当前任务书即可。

## 当前状态

- `N1-N60` 已基本落地，文档/静态 UI/文案/样例类任务已经形成稳定套路。
- 现在主计划已经推进到 `P2` 阶段，`P2-2` 到 `P2-10` 这批语音/训练链路目前是“已接线，待验收”为主。
