# 获面通：新手五分钟上手指南

> 面向第一次打开获面通的用户。  
> 跟着走完这 7 步，就能完成一次完整的面试辅助流程。

---

## 第一步：安装与启动

1. 双击安装包 `获面通 Setup x.x.x.exe`
2. 安装完成后双击桌面快捷方式启动
3. 你会看到左侧导航栏和默认的面试台页面

> **注意**：Windows 可能提示"未知发布者"，点击"更多信息"→"仍要运行"即可。

## 第二步：配置 API Key

AI 回答和语音转写都需要 API Key。

1. 点击左侧导航栏的 **⚙️ 设置**
2. 在"提供商列表"中找到 **DeepSeek**
3. 填写你的 DeepSeek API Key（从 [platform.deepseek.com](https://platform.deepseek.com) 获取）
4. 往下找到 **Deepgram**，填写 Deepgram API Key（从 [deepgram.com](https://deepgram.com) 获取）
5. 分别点击它们的 **"测试连接"** 按钮，确认显示成功
6. 点击左上角的 **"保存设置"**

> 💡 没有 Deepgram Key 也可以先手动输入问题体验。

## 第三步：导入候选人简历

1. 点击左侧导航栏的 **📋 简历库**
2. 填写"候选人姓名"和"应聘岗位"
3. 在"正式简历"区域点击上传，选择一份 PDF 或 DOCX 简历
4. 点击右上角 **"保存简历"**

> 💡 简历越详细，AI 回答越精准。后续可以在"万字简历"中补充更多经历。

## 第四步：开始面试

回到 **🎤 面试台**：

1. 在底部输入框中输入面试官的问题
2. 按 `Ctrl + Enter` 或点击 **"生成回答"**
3. 稍等几秒，你会看到：
   - **等待话术**（过渡语）
   - **正式答案**（基于简历的 AI 回答）
   - **依据来源**（标注了回答来自哪份简历）

## 第五步：开启语音转写（可选）

1. 在面试台左侧的"语音设置"面板中
2. 选择你的麦克风设备
3. 点击 **🎤 麦克风** 按钮
4. 面试官说话时，实时转写会自动显示
5. 再次点击按钮停止转写

> 💡 没有麦克风也可以用"模拟转写"或手动输入问题。

## 第六步：保存会话

1. 面试结束后，点击 **"保存会话"**
2. 输入会话名称（如"数据分析面试-2026-07-22"）
3. 保存后去 **📁 会话记录** 查看

## 第七步：导出文档

1. 在会话记录中打开刚保存的会话
2. 点击 **"导出 MD"** 或 **"导出 Word"**
3. 选择保存位置，即可生成面试记录文档
