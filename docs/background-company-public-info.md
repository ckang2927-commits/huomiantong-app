# 公司背景公开资料说明

> 说明联网搜索公司公开资料的最终产品设计，本轮不做联网实现。

---

## 最终能力说明

未来版本中，用户输入公司名称后，系统可以：

1. 调用联网搜索获取公司公开资料（官网、招聘页、新闻、财报）
2. 自动提取关键字段：主营业务、规模、融资、地址、竞品
3. 标记每条信息的来源 URL 和抓取日期
4. 用户确认后保存到"其他简历"

## 需要联网的字段

| 字段 | 建议来源 | 可信度 |
|------|----------|:------:|
| 公司全称 | 官网/企查查/天眼查 | 高 |
| 主营业务 | 官网/招聘页产品介绍 | 高 |
| 公司规模 | 招聘页/企查查/财报 | 中 |
| 融资情况 | 36氪/IT桔子/企查查 | 中 |
| 总部地址 | 官网"联系我们" | 高 |
| 主要竞品 | 行业报告/36氪 | 中 |
| 行业排名 | 行业报告/AI 估算 | 低 |
| 最近新闻 | 36氪/百度新闻 | 中 |

## 来源记录模板

```
来源：公司官网 - 关于我们
URL：https://example.com/about
抓取日期：2026-07-22
可信度：中（官网通常准确，但可能宣传成分）
```

## 不用联网也能做的准备

- 用户已知的公司信息（填过的 JD、面试通知里的介绍）
- 简历和已有材料中包含的公司信息
- 面试邀请邮件/电话中的细节
