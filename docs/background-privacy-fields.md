# 背景资料补全 — HR 隐私字段提示

> 面试中有些问题涉及隐私，可以跳过或泛化回答。
> 提前标记这些字段，面试时不会措手不及。

---

## 隐私字段分级

| 等级 | 含义 | 建议 |
|:----:|------|------|
| 🟢 可回答 | 不影响隐私，建议如实回答 | 如实回答 |
| 🟡 可选择 | 可回答但可以泛化 | 给大概范围，不需要精确 |
| 🔴 可跳过 | 涉及隐私，可以礼貌拒绝 | 说"这个不方便透露"或换话题 |

## 字段隐私分级

| 字段 | 等级 | 建议回答方式 |
|------|:----:|-------------|
| 现住址（精确门牌） | 🔴 | "住在朝阳区望京附近" |
| 现住址（大概区域） | 🟢 | 直接说区域 |
| 婚姻状况 | 🔴 | "这个和岗位关系不大" |
| 是否有小孩 | 🔴 | "目前没有这方面的负担" |
| 父母职业 | 🔴 | "这个不太方便透露" |
| 大学 GPA | 🟡 | "大概 3.5/4.0" |
| 高考分数 | 🟡 | "不太记得了，大概 XX 左右" |
| 年龄/出生年份 | 🟡 | 可以直接说 |
| 身体健康状况 | 🔴 | "身体健康，可以胜任工作" |
| 是否有犯罪记录 | 🟢 | 如实回答 |
| 社交媒体账号 | 🔴 | "抱歉，我不太分享个人社交账号" |
| 上家公司名称 | 🟢 | 如实回答 |
| 为什么离开上家 | 🟢 | 聚焦业务/发展，不抱怨 |
| 空窗期做什么 | 🟢 | 如实说学习/休息/找工作 |
| 有没有其他 offer | 🟡 | "还在看机会" 或 "有在谈的" |

## 隐私模式的配合

当隐私模式开启时：

- 导出文档自动脱敏（替换名称、公司、地址）
- 悬浮窗展示脱敏版本
- 保存到"其他简历"时自动处理敏感字段

## 如果不确定怎么回答

```
"这个问题我可能需要想一下，我们可以回头再聊吗？"
"这个信息目前不太方便详细说，但不影响我的工作能力。"
"我更倾向于聚焦在岗位和业务上，隐私方面希望能理解。"
```
